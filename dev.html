開発者向けガイド

mycmux は、複数のエージェントをタブで動かすターミナルワークスペースです。ここでは固定した配布版のソースをもとに、構成と受け渡しの約束を説明します。操作の手順は使い方にあります。

全体の地図#

本体は、タブ、端末、保存、状態の観測と制御 API を受け持ちます。製品固有の起動や記録はアダプター、仕事の分け方や品質の基準は利用者の手順です。この区分は設計の原則で、すべての実装が移し終わったことを示すものではありません。

ページの一覧#

ページ読む内容
境界制御 API、hook、環境変数、同梱の手順です。
エディタ本体型、端末の出力、保存、配置、窓と Web です。
観測とカード状態の根拠、画面の表示、人が応じる操作です。
ディスパッチ起動、送信、引き継ぎと結果の確認です。
再開会話の対応、復元、再開と休止です。
エージェントの家未実装の設計と、使える機能の違いです。
周辺の仕組み使用量、ログ、保存記録、再配置と点検です。
いま動いているものソース上の処理、保存先と実機確認の境界です。
設計文書と実装文書の判断と、配布版にある実装の照合です。
立ち位置と約束責務、識別子、操作の結果と制限です。
用語画面の呼び名と、変えていない API 名です。

主な仕組み#

仕組み確かめられること
タブと窓動いたまま移し、保存した窓の配置を復元します。
制御 API と CLI版と能力を照会し、起動、状態、送信、読取、終了を扱います。
CLI の全件の status入力改訂番号の null を許します。送信の期待値には使いません。
会話履歴Claude Code と Codex の全過去をページごとに読みます。
受け取り箱外部報告の最近 20 件を読む入口です。
エージェント設計設定の本文、比較、点検と HTML の書き出しです。

画面と本文を対応させる#

画面 1 つはタブ、画面を割った場所は表示場所です。コードの Pane、PaneTab、API の pane.* は名前を変えていません。型と画面の対応で、それぞれの意味を確認できます。

ソースを読む順番#

  1. 関係する ADR で、設計の約束を読みます。
  2. CHANGELOG と、画面の文字を定義したソースを照合します。
  3. 制御 API と、操作を受け持つ実装をたどります。
  4. テストの対象と、実機で確認した範囲を分けて読みます。

確認の範囲#

このガイドは配布版のソースの説明です。利用者の実機の稼働回数、使用量、DB の大きさを示すものではありません。実際の状態は、制御 API と診断記録で確かめてください。

画面から確かめる入口#

窓の操作は配置と窓、会話の復元は再開にあります。設定が何を読むかはエージェント設計から確認できます。
