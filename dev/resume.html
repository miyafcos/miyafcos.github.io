resume と継続

同じ会話の再開、要点を渡す引き継ぎ、画面を戻す復元を分けて説明します。タブの名前や最新のログだけから、会話を推測して開き直しません。

何を覚えているか#

記録受け持つこと
data.json作業場、タブ、作業フォルダと保存した配置です。
pane-sessionsタブとエージェント製品の会話 ID の対応です。
会話のファイル発言と、製品が保存した起動の情報です。
セーブポイント要約、引き継ぎ書、復元情報をまとめます。
窓の復元情報開いていた窓のまとまり、位置、大きさです。

起動時の復元#

保存したタブと会話の対応を読み、重複を確かめて配置を戻します。全タブを一斉に起こさず、表示したタブから起動します。切り離した窓も、保存したまとまりと位置へ戻します。

Codex は、保存された会話 ID で同じ会話をそのまま開きます。復元できない場合は、そのタブだけ新しい会話で始め、一度だけ知らせます。別の最新の会話を代わりに開いたり、同じ会話を二重に起動したりはしません。

種類ごとの再開#

種類読み分けること
Claude Code保存された ID と、会話の記録を確かめて再開します。
Codex保存された ID を指定して再開します。
claude-codex対応するランチャーの再開経路を使います。
Grok Build保存された ID による復元と、Resume の一覧を区別します。
Cursor新規起動だけに対応し、再起動ではランチャーへ戻ります。
agy、Hermes、Oh My Pi新規起動の対応と、会話の追跡を区別します。
シェル作業フォルダや出力を戻し、AI の会話は再開しません。起動用のコマンドも流し直しません。

Grok の会話は Resume の一覧には出ません。agy、Hermes、Oh My Pi も、会話の再開や引き継ぎの対象外です。

再開時のモデルと effort#

起動時の一時指定と、再開時に製品の記録から読む値は別です。Claude の再開では、最後の実際の返答から effort（考える深さ）を読み取ります。記録がなければ既定を使い、明示した指定があればそちらを優先します。

すべての製品が、同じモデルと effort を保持する保証ではありません。CLI から適用できない組み合わせを指定した場合は、起動前に断ります。

休止#

休止は、プロセスを終了してメモリを返す操作です。会話の記録は読んだり再開したりできますが、途中の実行状態は戻りません。完了だけが未読なら、会話の保存を確認してから休止できます。

作業中、権限待ち、質問待ちは候補から保護します。ただし休止の判定は、ダッシュボードの新しい作業中判定とは別です。長い道具や見張りが動く裏のタブも、時間が来ると止まる場合があります。

手動の再開#

入口動き
Resume過去の会話を検索し、選んで開きます。
「続きから」同じ一覧の直近の候補から選びます。
「閉じたタブを開き直す」閉じたタブの記録から戻します。
「セッションを複製」別の会話を作り、元の会話を残します。
セーブポイント要点から引き継ぐか、記録から続きを開きます。

人の発話がない会話は、Resume の一覧に出ません。アプリの復元、会話履歴の閲覧、Resume の検索は別の入口です。

会話の持ち主を確かめる#

別のタブで動いている会話には、その場所が出ます。「そちらを開く」「こちらで開き直す」「新しい会話で始める」から選びます。相手を止めて開き直すときは、先に確認します。

相手が終わった場合の自動再開は、一度だけです。自動ジョブだけの記録は、元の会話、そのまま、新しい会話から選べます。

タブと会話の対応表#

~/.mycmux/pane-sessions/<タブの ID>.txt に、種類と会話 ID を残します。移動したタブの対応も保ち、現在の所属の読み取りと作成時の ID を区別します。起動、モニタ、hook の材料を、会話の所有者の確認に使います。

利用者の hook と、起動の指定#

再開や引き継ぎの一時変数は、新しいタブや保存へ漏れないように除きます。利用者の hook による要約の追加は、その環境の設定として扱います。同じ会話の再開と、新しい会話への文脈の追加を混ぜないでください。

似た名前を読み分ける#

PTY セッション ID、タブ ID、会話 ID、セーブポイントの ID は別です。--resume-session の相手と、送信の --session の相手も区別します。用語に、各 ID の用途があります。

実機で確かめること#

保存した ID が復元されたか、知らせが一度だけか、窓の位置が戻ったかを確認します。失敗した場合は、そのタブの記録と診断を照合します。検査の成功だけで、各 OS の復元がすべて確認できたとは扱いません。
