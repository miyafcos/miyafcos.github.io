用語と取り違えやすい語

画面の名前からコードを探すときは、意味を確かめて対応させます。日本語の呼び名が変わっても、API や保存データの識別子はそのままです。

基本の語#

語指すもの
ワークスペース案件や調査ごとの作業のまとまりです。
タブ端末、Web、資料、オンライン、起動メニューなどの画面 1 つです。
表示場所タブを並べるために画面を割った、1 つの場所です。
裏のタブ同じ表示場所に重なり、いま表示していないタブです。
Workspaceワークスペースの保存と配置を表す型です。
Pane表示場所と、そこに置くタブのまとまりを表す型です。
PaneTabタブ 1 つの型です。
セッションタブの中の実行や、エージェント製品の会話を指します。対象を添えて読み分けます。
PTYシェルや CLI と文字をやり取りする、疑似端末です。
hook製品が出来事を外へ知らせる仕組みです。
アダプター製品固有の引数や記録を共通の操作へ対応させるコードです。

「タブグループ」は ADR にある後続工程の設計です。配布版の「表示場所」と同じ機能がすでにある、と読み替えないでください。

ディスパッチを読み分ける#

名前意味
委譲別のエージェントに仕事を任せる手順です。
dispatchBatch指定した複数の宛先へ入力を配る処理です。
委譲の見守り台帳を読み、人が見る必要のある状態を知らせる機能です。
コマンドの振り分け受けた API を、処理を持つ窓や関数へ渡します。

カードと受け取り箱を読み分ける#

名前示すもの
質問カードClaude Code の質問と、答える選択肢です。
気づきカード対応が必要なタブの事実です。
実行契約カード目的、素材、役割、完了条件を確認する入口です。
受け取り箱外部から届いた報告です。最近 20 件を開けます。

動いている会話には、静かな時間だけを理由とする気づきを出しません。コードに残る過去の報告欄の名前と、現在の受け取り箱は区別して読みます。

判定と判断を読み分ける#

状態の合成は、情報源と時刻を使う処理です。次の一手や Jev は、AI を使う任意の判定です。仕事が正しいかを採る判断は、成果物と検証結果を読む人や手順に残ります。

再開、引き継ぎと ID#

名前指すもの
再開同じ会話 ID で、会話の続きを開きます。
引き継ぎ要点を別の会話へ渡します。
復元保存した画面や窓を戻します。会話の再開とは別です。
タブ IDタブと保存記録を結び付けます。
PTY セッション ID制御 CLI の送信や読取の宛先です。
会話 IDエージェント製品が保存した会話を識別します。
起動の世代同じタブでも、前の実行からの知らせを区別します。

環境変数 MYCMUX_PANE_SESSION_ID と MYCMUX_TAB_ID は改名していません。ID の形から、現在所属するワークスペースを推測しないでください。

名前が似ている別物#

session_state は実行時の状態、pane-sessions はタブと会話の対応表です。history.db のイベント、会話履歴、Resume の一覧も、それぞれ別の読み取りです。復元の対応と境界に詳しくあります。
