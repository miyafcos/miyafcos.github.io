いま動いているもの

このページでは、配布版のソースにある処理と保存先を整理します。実機のプロセス数やファイルの大きさは、利用者の環境で確かめてください。

確認を分ける#

確認分かること
実装と呼び出し元処理がどの条件で呼ばれるか。
状態と画面の読取その時点のタブや会話の状態。
診断ログ記録された失敗や回復の経過。
実機の観測その環境で実際に起きたこと。

記録が見つからないことだけで、使われていないとは判断しません。

アプリの処理と読み取り#

処理受け持つこと
PTY モニタと出力の保存前景のプロセス、作業フォルダ、端末の出力を追います。
状態の配信と会話の読取状態と、会話の意味のある出来事を画面へ渡します。
ライブの画面別の作業場や裏のタブも読み、末尾と状態、その状態になってからの時間を表示します。
アカウントと使用量取得した状態と時刻を更新します。
自動命名そのタブの題名、指示、起動時の名前から決めます。取得できなければ理由を出します。
自動保存と窓の復元保存した配置と、開いていた窓を戻します。
休止と掃除候補と保護の理由を確認し、プロセスを終えます。

自動名の優先順と前回の名前を保つ条件は、自動命名にまとめています。

描画が落ちると、Windows と Mac で画面を読み込み直します。Windows の応答停止も対象で、裏の端末は作業を続けます。回復には回数と間隔の上限があります。

データの置き場#

置き場中身
アプリの保存領域の data.jsonワークスペース、タブ、配置と設定です。
scrollback/端末の表示履歴です。
~/.mycmux/pane-sessions/タブと会話の対応です。
~/.mycmux/agent_design/エージェント設計の目録です。
~/.mycmux/diag.log起動、固まり、描画や処理の診断です。
~/.mycmux/ailog.db AI ログの索引と集計です。
~/.mycmux/history.db会話から読んだイベントの記録です。

導入済みの制御 CLI は、更新後の起動時に同梱の最新版へ追従します。手で変更した CLI は保護し、更新前の版は控えとして残します。

外から読める入口#

API や CLI確認や操作
system.version本体の版と能力を照会します。
pane.live_tailsタブの画面の末尾を読みます。
pane.screen端末の表示範囲の文字と属性を読みます。
pane.capture端末の表示範囲を PNG で読みます。
agent_design.refreshエージェント設計を読み直します。
account.usage PC と同じ区分のアカウントと使用量を返します。
account.switch PC の画面と同じ処理でログインを切り替えます。
account.use_reset_ticket PC の確認と同じ処理でリセット券を使います。
inbox-post外部報告を受け取り箱へ取り込みます。

「mycmux Control plugin」は、状態、タブの一覧、指定したタブの画面を読む入口です。「Grok Bot (アプリ)」は導入済みのアプリを開く入口です。仕事の受付と完了は区別し、通信に失敗しても自動では再送しません。

確認の制限と試験機能#

外部の Web タブは、端末、ファイル、設定、更新、窓の操作から権限を分けています。データの一部を読める経路は残るため、信頼できないサイトは開かないでください。

DeepSeek Harness の ACP 接続と Codex App Server は試験の設定です。DeepSeek Harness の接続は既定でオフで、実配布版の ACP と Windows の動作は未確認です。標準の使い方は導入と設定を参照してください。

端末の表示崩れを調べる記録は、通常はオフです。有効にした場合も、本文、入力、名前、パスを記録せず、記録量を制限します。
