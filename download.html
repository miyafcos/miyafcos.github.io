ダウンロード

下のボタンは版番号を含まないので、いつ押しても最新版が落ちてきます。入れたあとの変更は最近の変更にまとめています。

お使いの OS を選びます#

Windows 10 と 11（64bit）macOS（Apple Silicon と Intel）

Windows 10 と 11（64bit）#

Windows 版をダウンロード

インストーラ（.exe、約 34.4 MB）。実行するだけで入ります。
MSI 版（約 40.1 MB）もあります。

macOS（Apple Silicon と Intel）#

Mac 版をダウンロード

ディスクイメージ（.dmg、約 84.5 MB）。両方の CPU がこの 1 つに入っています。
Intel Mac での実機確認は未了です。

配布ページ（全ファイル）　以前の版の一覧

入れたあとにすること#

Windows の配布物には、発行者のデジタル署名が付いていません。SmartScreen が出たら「詳細情報 → 実行」で進めます。

macOS では、dmg を開いて mycmux.app を「アプリケーション」へ入れます。初回起動が止められたら、OS に合う操作を選びます。

OS初回に開く操作
macOS 14 までFinder でアプリを右クリックし、「開く」を選びます。
macOS 15 以降一度起動を試した後、「システム設定 → プライバシーとセキュリティ → このまま開く」を選びます。

2 回目からは普通に開けます。コマンドによる方法は、はじめるにまとめています。

使いたいエージェントの CLI は別に用意します。CLI は、端末でコマンドを入力して使うプログラムです。Claude Code や Codex を、普段の端末で起動できる状態にしておいてください。

導入の手順と最初の 10 分は、はじめるにまとめています。

2 回目からは更新ボタンで#

一度入れたあとは、アプリの「設定 → アプリ情報 → 更新を確認」から新しい版に上げられます。新しい版があると画面右上に青い更新マークが出て、押すと同じ確認枠が開きます。「更新して再起動」か「あとで」を選べます。このページからダウンロードし直す必要はありません。

Android や iPhone から使う#

スマホ用のアプリ「ポケット」は、開発版を配布しています。取得には、配布先と同じ Tailscale ネットワークへの参加が必要です。iPhone 版は、配布対象として登録済みの端末に限ります。

Android 版のダウンロードと使い方iPhone 版のインストール

対応 OS や注意点は、ポケットの入手案内で確認してください。

PC 側の接続準備は、ポケットの接続条件にまとめています。
