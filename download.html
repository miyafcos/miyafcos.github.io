お使いの OS を選びます

Windows 10 と 11（64bit）

最新版をダウンロード

インストーラ（.exe、約 17 MB）。実行するだけで入ります。
MSI 版（約 21 MB）もあります。

macOS（Apple Silicon と Intel）

最新版をダウンロード

ディスクイメージ（.dmg、約 46 MB）。両方の CPU がこの 1 つに入っています。
Intel Mac での実機確認は未了です。

配布ページ（全ファイル）　以前の版の一覧

入れたあとにすること

Windows では、配布物に Authenticode 署名が付いていません。SmartScreen が出たら「詳細情報 → 実行」で進めます。

macOS では、dmg を開いて mycmux.app を「アプリケーション」へ入れます。Apple の開発者署名が無いので、初回だけ右クリック（または Ctrl を押しながらクリック）して「開く」を選びます。2 回目からは普通に開けます。

使いたいエージェントの CLI は別に用意します。Claude Code や Codex を、普段の端末で起動できる状態にしておいてください。

導入の手順と最初の 10 分は、はじめるにまとめています。

2 回目からは更新ボタンで

一度入れたあとは、アプリの「設定 → アプリ情報 → 更新を確認」から新しい版に上げられます。このページからダウンロードし直す必要はありません。
