mycmux は、ターミナルを並べる作業に、会話を引き継いで見守るための道具を足します。

したいことターミナルを並べるだけの場合mycmux
複数の作業を見る端末を並べて確認タブを分けて並べ、拡大もできる
窓を切り離す別の窓の起動と配置を自分で用意見出しを引いて窓にし、重ねて戻す
続きを任せる引き継ぐ内容と起動を自分で用意引き継ぎ書を添えて、可視タブで相手を起動

文書を確かめる文書を開く道具を別に用意会話の隣でプレビュー

比較は、ターミナルを並べる操作だけを対象にしています。拡張機能や別の道具を組み合わせた場合は含みません。

よくある質問

はじめる前に

どの OS で使えますか？+

Windows と macOS（Apple Silicon）で使えます。macOS の配布物は universal 形式ですが、Intel Mac での実機動作は未確認です。

エージェントも一緒に入りますか？+

Claude Code や Codex などは別に入れます。普段の端末で起動できる状態にしてから、mycmux で開いてください。

別のエージェントへ任せるには何が要りますか？+

Python 3 と委譲 CLI が必要です。委譲 CLI は公開リポジトリか「設定 → AI → Claude Code スキル」から導入できます。

スマホからも使えますか？+

接続には、PC 側でポケットの接続用サーバの準備が必要です。iPhone でできることと入手の状況をご覧ください。

どんな文書を開けますか？+

Markdown、HTML、Word、Excel、PowerPoint、PDF とテキストを開けます。

ライセンスは何ですか？+

GPL-3.0 です。ソースとライセンスを公開しています。
