はじめる

まず、作業フォルダをひとつ決めます。インストールしたら、2 つのエージェントを並べ、作業の区切りを残すところまで進めます。

インストール

mycmux と、使いたいエージェントの CLI は別々に用意します。CLI は、端末で起動して使うプログラムのことです。Claude Code や Codex を、普段の端末で起動できる状態にしておいてください。

Windows

  1. ダウンロードのページで、Windows のボタンを押します。版番号を選ぶ必要はありません。
  2. 落ちてきたインストーラ（mycmux-windows-x64-setup.exe）を実行します。

配布物に Authenticode 署名は付いていません。配布元とファイル名を確かめてから実行してください。SmartScreen が出たら「詳細情報 → 実行」で進めます。

macOS

  1. ダウンロードのページで、macOS のボタンを押します（mycmux-macos-universal.dmg）。
  2. dmg を開き、mycmux.app を Applications へドラッグします。
  3. 初回起動が止められたら、次の表から OS に合う操作を選びます。
OS初回に開く操作
macOS 14 までFinder でアプリを右クリックし、「開く」を選びます。
macOS 15 以降一度起動を試した後、「システム設定 → プライバシーとセキュリティ → このまま開く」を選びます。

どちらの OS でも、次のコマンドを一度実行する方法があります。ダウンロードしたアプリの隔離属性を取り除くので、配布元を確かめたファイルだけに使ってください。

xattr -cr /Applications/mycmux.app

この手順は Apple Silicon 向けです。配布物には Intel 向けのバイナリも入っていますが、Intel Mac での実機動作は未確認です。

最初の 10 分

キーの表記は Windows が基準です。macOS では Ctrl を Cmd に読み替えてください。OS の切り替え操作と重なるときだけ、Ctrl のまま押します。

1. 作る：作業フォルダを選ぶ

初回の画面で「フォルダを選んで開始」を押し、作業するフォルダを選びます。案件ごとに分ける作業場をワークスペースと呼びます。その中に並ぶ端末の区画がタブ、タブの中で切り替える単位がペインです。

選ぶボタン始め方
「ホームで新規ワークスペース」ホームフォルダに 1 ペインを開きます。
「フォルダを選んで開始」選んだ作業フォルダから始めます。
「詳しく設定して作成」エージェントやレイアウトも選んでから作ります。

2 回目からは Ctrl+Shift+N で作れます。現在のフォルダを引き継いで、すぐに作成します。レイアウトも選びたいときは、Ctrl+Shift+Alt+N で設定画面を開きます。

2. 立てる：Claude Code を起動する

ペインに出る起動メニューがランチャーです。「新規に起動」の「Claude Code」をクリックします。「打って探す / そのまま選ぶ」の検索欄から探しても構いません。

モデルを指定したいときは、矢印キーで Claude Code を選んで Tab を押します。effort は、推論の深さを指定する設定です。「モデル」「effort」を選び、「起動」を押します。迷ったら、両方とも「既定」のままで問題ありません。

起動すると、ペインにエージェントの名前と状態ドットが出ます。

ペインの下の「Claude メッセージを入力」に指示を書けます。Enter で送り、改行だけなら Shift+Enter です。

3. 並べる：右に分割して Codex を起動する

Ctrl+Alt+D で右に分割します。新しいタブのランチャーで「Codex」をクリックします。2 つの出力を見比べ、片方を読み込みたいときは Ctrl+Shift+Enter で拡大します。

新しく分けたタブにもランチャーが出ます。

全景の中央にある「shell」は、シェル用のペインです。文字のランチャーが出ている場合は、下端の「Esc/q: shell」の案内でシェルへ戻れます。GUI のランチャーで Esc を押す操作とは異なります。

4. 開く：成果物をプレビューする

エージェントがファイルを作ったら、出力に出たパスをクリックします。Markdown、HTML、Office 文書は、アプリ内のプレビューが対象です。それ以外の形式では、「既定のアプリで開く」「エクスプローラーで表示」を選べます。

たとえば、作業フォルダの docs/summary.html を作ったら、そのパスを会話に出してもらいます。

上部には「この文書を編集」「既定のアプリで開く」「ファイルの場所を表示」があります。編集や外部アプリへの移動を、プレビューから選べます。

5. 残す：セーブポイントを作る

会話の要約、引き継ぎ書、復元情報をまとめた記録がセーブポイントです。タブのペインバーにある「セーブポイントを作成」を押します。作業途中の記録は何度でも更新でき、終了時には変更しない区切りの記録を残せます。

保存した一覧の入口は、タイトルバーの「セーブポイントを開く」です。作成ボタンと一覧ボタンは同じしおりの形ですが、場所と名前が違います。

「記録の見出し」は空欄でも構いません。最後の指示から自動で付けます。会話ログがまだない場合は、エージェントと 1 往復してから保存します。

一覧では「受け取る」で記録を取り込み、「更新」で表示を読み直します。「保存済み」と「ゴミ箱」を切り替え、残っている記録を確かめます。

6. 更新する：更新を確認する

「設定 → アプリ情報 → 更新を確認」を押します。更新があれば、署名の検証とダウンロードの後に自動で再起動します。更新が始まるのは、この操作をしたときだけです。

作業中の文書を保存してから「更新を確認」を押し、表示される結果を確かめます。更新中はアプリが再起動するため、戻ったらワークスペースと会話の状態を確認してください。

本番と分けて試したい

普段の設定に触れずに試すには、Windows の端末から次のように起動します。実行ファイルに PATH が通っている場合の例です。

mycmux.exe --profile trial

設定、接続先、ログ分析用のデータが本番と分かれ、タイトルバーに赤いバッジ「TEST」とプロファイル名が出ます。テスト中は、アプリの更新と使用量の定期取得が止まります。プロファイル名に使えるのは英数字とハイフン、アンダースコアで、長さは 1〜64 文字です。

困ったとき

症状確かめること
エージェントが起動しない普段の端末で claude や codex が起動するか確かめます。CLI のインストールと PATH の設定が必要です。
過去のセッションを一覧できないResume の履歴ツール crsm は別途必要です。準備手順を確かめます。
古い版から自動更新できないv0.21.2 以前は、固定 feed から新しいインストーラを一度手動で実行します。
旧 lite 版を使っているlite 版の配布は 2026-07-23 に終わりました。通常版のインストーラを入れ、旧 mycmux-lite はアンインストールします。ワークスペースの設定は引き継がれません。
バッジや保存ボタンが出ない独自のラッパーを介して起動していないか確かめ、ランチャーからの起動を試します。
起動しない、途中で落ちる診断ログ ~/.mycmux/diag.log を確かめます。

同じ版が二重に見えるときは、Windows のインストール済みアプリを確認します。ユーザー用と全ユーザー用が重複している場合は、使う方を決めて整理します。

macOS で登録済みの使用量が出ないときは、版番号も確かめてください。取得の経路はあとの版で直しています。

解決しないときは、公開リポジトリの Issues で既知の問題を探せます。

次は、実務の流れか、目的別の操作へ進んでください。
