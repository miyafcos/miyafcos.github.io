アカウントと設定

アカウントと使用量、コストの内訳、見た目とキー、AI と自動化、スマホからの接続とキャラクターの設定です。末尾に、よく使うキーと用語の一覧を置きました。操作の基本は画面と操作に、委譲や保存はエージェントとの作業にあります。

アカウントと使用量を確かめたい#

タイトルバーの「アカウントと使用量」で、使用中のアカウントと取得できた使用率を見ます。詳しくは「設定 → アカウント・使用量 → アカウント別の使用量」へ進みます。取得時刻も一緒に確かめます。

行をクリックすると、PC 全体の CLI ログインが切り替わります。mycmux 内で動いているセッションがあれば確認が出ますが、アプリの外の CLI は検知できません。Codex はアカウントごとの使用量を取れないため、空いている枠の比較には使えません。

追加は「+ アカウントを追加」から行います。現在のログインを壊さない隔離ログインで登録します。

Claude の使用量取得は、非公式の接続先を使います。追加や自動取得にはアカウント制限のリスクがあるため、設定画面の説明を読んでから使ってください。

表示読み方
「5h」「7d」5 時間枠と週次枠の使用率です。
モデル別の週次枠接続先から取得できた枠を表示します。
「取得時刻」「状態」値の新しさと、取得できない理由を確認します。

取得を休んでいる間も、前回の値を薄く表示します。再開予定の時刻は推定です。

自動でアカウントを切り替える#

「設定 → アカウント・使用量」で、プロバイダーごとに自動切り替えを設定できます。既定はオフです。

エージェントごとに、一覧の「候補」で切り替え先を選べます。

新しく登録したアカウントは、最初から候補に入ります。

5 時間枠か週次枠が上限に達すると、候補のうち空きがいちばん多いアカウントへ移します。

判断に使う使用量は、5 分以内に取得できたものだけです。不明な枠を空きとは扱わず、端末の一般的な HTTP 429 だけでも切り替えません。

候補に空きがなければ知らせて、オンのまま待ちます。

切り替え失敗、切り替え後の警告、切り替えても上限が続くときはオフになります。

自動の場合も PC 全体の CLI ログインに効くため、アプリ外の作業も含めて使い方を決めてください。

何にコストがかかったかを見たい#

タイトルバーの「AIログ分析」を開きます。ailog は、ローカルのエージェントログを索引する機能の名前です。画面を開くだけでは、言語モデルを起動しません。

期間は「7日」「30日」「90日」「今年」「全期間」「カスタム」から選びます。円換算のレートは手入力です。「記録は〜まで」「未取り込み」の表示で、集計の範囲を確かめます。

「何に使ったか」には、実装や検証などの作業種別が出ます。推移の棒を選ぶと、その期間に絞れます。セッション一覧の「主題」からは、個別の詳細へ進めます。

表示する金額はログと単価から出したコスト相当で、請求額そのものではありません。集計には既知の課題もあるため、欠落や未取り込みを含む参考値として使います。

見る場所分かること
「この期間」期間合計とコスト変化の要因です。
「何に使ったか」実装、検証、調査などの作業種別です。
「つまずいた場所」失敗の多いコマンドや、書き直しの多いファイルです。
「推移」日、週、月ごとの変化です。棒を押すと期間を絞れます。
「2つの切り口で比較」任意の 2 軸で比べます。セルからセッション一覧へ進めます。
「セッション一覧」検索、並べ替え、個別の詳細です。
「稼働リズム」稼働日や、作業の多い曜日と時間帯です。

指標は入出力トークン、総トークン、ターン数、セッション数、コスト相当から選べます。モデル、会社、案件などでまとめ直せます。

「カスタム」の期間は、開始日と終了日の両方を選んで確定します。取り込みをやり直す場合は、上部の「⋮」から「再インデックス（全量）」を選びます。

詳細では、作業フォルダや要約、ターンごとのコスト相当、ツールの実行結果を確かめられます。「会話を読み込む」で本文を読み込みます。「このセッションを要約する」は、AI を有効にしているときに使えます。

かんたん設定から選ぶ#

  1. 「外観」の「かんたん設定」を開きます。
  2. 「塗りつぶし」「すりガラス」「クリア」から、背景の見え方を選びます。
  3. おすすめの「石墨」「極夜」「月白」からテーマを選びます。
  4. 「文字の大きさ」を「小」「中」「大」から選びます。
  5. 端末フォントの見本を見て、読みやすい書体を選びます。
端末フォントの分類選ぶ目安
「コード・標準」普段のコードやログの表示です。
「日本語・表の読みやすさ」日本語の文章や表の読みやすさを見ます。
「印象を変える」教科書体や明朝体を選べます。

表のプレビューで、数字や罫線の揃い方も確認してください。下の画像は「かんたん設定」の上部と、おすすめの「石墨」「極夜」のカードです。

詳しく調整する#

調整選べること
描画方式通常の描画が合わないときに、方式を切り替えます。
壁紙用意された 11 枚、ローカルの画像、単色です。
背景のスライダー画像の不透明度、ぼかし、壁紙の色調、パネル、ターミナルです。
画面の密度「つめる」「標準」「ゆったり」です。
色の個別変更基本の配色と、端末の ANSI 色を調整します。

「塗りつぶし」では、パネルとターミナルの透過調整は使えません。テーマを変えると色の個別調整は戻るため、変更後の表示を確認します。取り消しのトーストから元へ戻せます。

WebView2 の標準の右クリックメニューは出しません。操作は「⋮」ボタンとドラッグに寄せてあり、右クリックでの選択コピーは使えます。

キーの変更中に Backspace か Delete を押すと、その割り当てを外せます。重複する割り当ては赤く表示されるため、保存後のキーを確かめます。

壁紙は「すべて」「暗め」「中間」「明るめ」で絞り、キーワードでも探せます。ローカル画像のパスを使うこともできます。

配布物に入れていた 48 枚は、再配布の権利を確かめられなかったため外しました。同じときに「macOS」「Warp」などの分類での絞り込みもなくなっています。

「主要色」は、背景や文字、カーソルなどを 1 色ずつ変える入口です。ANSI 16 色などは「詳細色」を開いて変えます。

AI と自動化を止めたい#

「設定 → AI」の「Claude Code スキル」から、3 つのスキルと委譲 CLI を導入、更新できます。

カードの状態操作
「未導入」「導入」で用意します。
「更新あり」「更新」で配布された内容へ更新します。
「最新」導入済みの内容を使えます。
「ローカル改変」変更内容を確認し、「退避して置き換える」を選びます。

前提は Claude Code と Python 3.10 以上です。導入時に問題があれば、カードの結果と「再確認」を使います。

「設定 → AI」の「エージェント連携」で、Claude Code、Codex、Grok の hook の状態を見られます。必要に応じて「入れる」「直す」「外す」を選べます。

「設定 → AI」の「AI機能を有効にする」が親スイッチです。オフにすると、ペインの自動命名や返信案の準備など、AI を使う機能がすべて止まります。「設定 → 自動化」では、見守り、自律モード、通知の敏感さ、休眠セッションの整理時間を決めます。

「自動化」の項目決めること
「見守りを有効にする」委譲した作業の定期確認です。
「通知の敏感さ」「控えめ」「標準」「敏感」などを選びます。
「見守りの通知を出す」確認結果を通知するか決めます。
「休眠セッションの整理」自動整理しないか、30 分、60 分、120 分後かを選びます。
「実行契約の次の作業を自動で始める」自律モードを切り替えます。
「先回りカード (気づき)」以前の気づきカードの仕組みを切り替えます。ダッシュボードの「気づき」列のカードは、この設定では止まりません。

AI の個別設定には、ペインの自動命名、返信案の準備、報告の要約、ペイン整理の判定があります。AI ログ分析の要約も個別に切り替えられます。

ペインの並べ替えは「ペイン再配置」から行えます（案の見方）。

ペイン再配置に Jev を使う#

Jev は、OpenRouter 経由でペインの関係を調べ、再配置案を作る機能です。

既定は無効で、有効にした場合だけ使います。

無効のままなら、ペイン再配置には従来の AI を使います。

  1. 「設定 → AI」で「AI機能を有効にする」をオンにします。
  2. Jev の再配置設定で、「OpenRouter APIキー」と「Jevのモデル」を入力します。
  3. 「接続テスト」を押し、結果を確認します。
  4. 「ペイン再配置にJevを使う」をオンにし、「Jev設定を保存」を押します。

API キーは、この端末の OS の保護機能で保存します。

再配置では、画面末尾の 12 行、ペイン名、作業フォルダ、親子関係を OpenRouter 経由で送ります。接続テストは短い確認データを送り、API の利用料が発生します。

案は、案件別、役割別、現在の位置を生かすものの 3 つです。関係の判定と適用後の確認は、ペインをまとめ直すにまとめています。

スマホやキャラクターを使いたい#

スマホからの接続と、デスクトップのキャラクターの設定です。

スマホから開く#

「設定 → スマホから使う」で、「ポケットmycmux」の接続先を確かめます。iPhone 用のアプリと入手の状況は、ポケットにまとめています。

QR コードと URL が出るのは、Tailscale の tailscale serve で /pocket を配信しているときだけです。設定を開くたびに接続先を調べるので、ホスト名が変わっても新しい URL を表示します。配信中でも応答がない場合は、URL の下に注意書きが出ます。

  1. PC 側で「ポケットmycmux」のサーバと、Tailscale の配信を用意します。
  2. 「設定 → スマホから使う」を開き、QR コードと注意書きを確かめます。
  3. スマホで QR コードを読み、ブラウザで「ポケットmycmux」を開きます。

現在、QR コードから iPhone アプリが直接起動することはありません。QR が出ない場合は、「ポケットmycmux」のサーバと配信の設定を確かめてください。

mycmux 内蔵のモバイル画面と、その接続用サーバはなくなりました。リモート接続の有効化、LAN 公開、接続中端末の一覧、トークンの再生成もありません。以前の接続設定は読み飛ばすため、設定ファイルを手で直す必要はありません。

Buddy とペット#

Buddy は、エージェントの活動に合わせて発話するデスクトップのキャラクターです。標準ビルド（配布版）では、既定の顔を表示します。

新しく入れたときは、キャラを表示しない状態（「キャラなし」）から始まります。以前の版から使っている場合は、保存されている選択がそのまま残ります。

ワークスペースのペットは「設定 → キャラ」で選びます。ワークスペースに 1 体出すか、表示しないかの 2 択です。「変更 ▸」で割り当てを変え、「今すぐ再スキャン」で追加したペットを読み直します。

ペットは候補に入れるものを選び、ワークスペースに固定するか、候補から選ぶかを決められます。「ギャラリー」で絵柄を確かめ、隔離したものは戻せます。

macOS での違い#

画面の分割だけは、読み替えの規則から外れます。Cmd+D で右に、Shift+Cmd+D で下に分割します。

Ctrl はタブの中のシェルへそのまま渡ります。Ctrl+C で止める、といったシェルの操作がそのまま使えます。

閉じるボタンと Cmd+W は、メインの窓を隠すだけです。ペインは動き続けるので、Dock のアイコンかウィンドウメニューから戻せます。終了はアプリのメニューの終了（Cmd+Q）で、開いていた窓と作業を保存してから終わります。

切り離した窓は標準の枠を持つので、窓を整えるアプリからも掴めます（ペインを窓に切り離す）。
