アカウントと設定

アカウントと使用量、コストの内訳、見た目とキー、AI と自動化、スマホからの接続とキャラクターの設定です。末尾に、よく使うキーと用語の一覧を置きました。操作の基本は画面と操作に、委譲や保存はエージェントとの作業にあります。

使う AI の入口を選びたい#

「設定 → 作業 → 使うサービス」で、サービスごとに表示を切り替えます。初回の確認後は Claude Code と Codex に加え、この PC で CLI が見つかったものを表示します。見つからないサービスも、自分でオンにできます。

オフにすると、ランチャーや新しいワークスペースの起動候補から外れます。エージェント設計、スキル、ふりかえり、履歴から再開する画面の選択肢にも効きます。記録済みのセッションや使用量は、オフにしても消えずに確認できます。

Web の項目は「設定 → ランチャー」で切り替えます。CLI は別に用意し、普段の端末で起動できる状態にしてください。

アカウントと使用量を確かめたい#

要点

  • タイトルバーの「アカウントと使用量」で、使用率と取得時刻を見ます。
  • 一覧で区分と契約プランを確かめ、追加や切り替えを選びます。
  • 切り替えは、この PC のエージェントのログイン全体に作用します。
使用量の取得の注意と、値の読み方タブごとのアカウントリセット券を使う自動でアカウントを切り替える

タイトルバーの「アカウントと使用量」で、使用中のアカウントと取得できた使用率を見ます。詳しくは「設定 → アカウント・使用量 → アカウント別の使用量」へ進みます。取得時刻も一緒に確かめます。

アカウント一覧は、使用量と取得状態で次の区分に分かれます。

区分読み方
「使用中」現在ログインしているアカウントです。
「切替候補」使用量を確認でき、上限に近くないアカウントです。
「残量わずか」上限に近いアカウントです。最初は畳まれています。
「制限中」上限に達したアカウントです。最初は畳まれています。
「確認が必要」使用量が未取得、取得に失敗、再ログインが必要などの場合です。

契約プランに加え、取得できた場合は「次回更新」か「有料期間終了」を表示します。取得できない日付は未取得と表示し、使用量のリセット時刻から推測しません。

行をクリックすると、PC 全体の CLI ログインが切り替わります。mycmux 内で動いているセッションがあれば確認が出ますが、アプリの外の CLI は検知できません。Codex も、登録したアカウントごとに取得できた使用量を表示します。

取得できない行は、認証や取得状態の説明を確かめます。

追加は「+ アカウントを追加」から行います。現在のログインを壊さない隔離ログインで登録します。登録後は、アプリの中のお知らせに「切り替える」が出ます。

押すと確認が出て、答えたあとにログインを切り替えます。

Mac の Claude の追加は、Keychain に保存されたログインも読み取ります。Codex や Grok の保存先の設定が違うときは、理由を表示します。

使用量の取得の注意と、値の読み方

Claude の使用量取得は、非公式の接続先を使います。追加や自動取得にはアカウント制限のリスクがあるため、設定画面の説明を読んでから使ってください。

表示読み方
「5h」「7d」5 時間枠と週次枠の使用率です。
モデル別の週次枠接続先から取得できた枠を表示します。
「取得時刻」「状態」値の新しさと、取得できない理由を確認します。

取得を休んでいる間も、前回の値を薄く表示します。再開予定の時刻は推定です。

「今回の取得は見送りました」は、その回の取得を見送った行に出る表示です。10 分以内に取れた値があれば、前回の数字を残します。使用中のアカウントから優先して取得します。

タブごとのアカウント#

ランチャーや新しいワークスペースの「アカウント」欄で、Claude Code、Codex、Grok のアカウントをタブごとに選べます。未登録のアカウントは「タブでも使う」から登録を始められます。

Claude は「始める」で claude setup-token が裏で動き、ブラウザの承認コードを貼って登録します。長期トークンは OS の秘密領域に保存します。この方式の Claude では、Claude.ai へのサインインが必要な機能は使えません。

Codex と Grok はタブ用ログインを使います。タブの名札と ⋮ の「このタブのアカウント」で確認状態や使用量を確かめられます。

リセット券を使う#

タイトルバーの「アカウントと使用量」で、Claude Code と Codex のリセット券を確認できます。券があるアカウントには、残数と、分かる場合は期限が出ます。券を押し、確認内容を読んで「使う」を選ぶと 1 枚使い、使用量を取り直します。

券を使える条件はアカウントによって違い、使えない理由も表示します。Claude Code は週のリセット日時を保ち、Codex は次に使った時点から週の枠を数え直します。確認画面で、戻る使用量と日時を確かめてください。

Claude Code の券は、直前の照会が通信の制限などで失敗しても申し込める場合があります。同じアカウントと組織の、10 分以内の確認結果が必要です。最終の判定はサーバ側で行い、認証のエラーや期限切れは対象外です。

自動でアカウントを切り替える

「設定 → アカウント・使用量」で、プロバイダーごとに自動切り替えを設定できます。既定はオフです。エージェントごとに、一覧の「候補」で切り替え先を選べます。

新しく登録したアカウントは、最初から候補に入ります。

5 時間枠か週次枠が上限に達すると、候補のうち空きがいちばん多いアカウントへ移します。

切り替えの間隔と確認

切り替えたあとは、その完了から 5 分以上あけます。判断に使う使用量は、5 分以内に取得できたものだけです。不明な枠を空きとは扱いません。

端末に一般的な「リクエストが多すぎる」（HTTP 429）が出ただけでも切り替えません。候補に空きがなければ知らせて、オンのまま待ちます。

切り替え失敗、切り替え後の警告、切り替えても上限が続くときはオフになります。自動の場合も PC 全体の CLI ログインに効くため、アプリ外の作業も含めて使い方を決めてください。

エージェントの設定と指示を見渡したい#

上の帯の剣と盾の印から「エージェント設計」を開きます。最初に出る「しくみ」の地図で、設定、指示、記憶、スキルの役割と置き場所を見ます。スキルは、エージェントが読む手順をまとめた文書です。Claude Code と Codex を 7 つの層で読み、Hermes は名前や有無、数を確認する範囲です。

7 つの層と、画面の使い分け
層画面の名前
1「本体（生身）」
2「実行の設定と権限」
3「指示とルール」
4「記憶と記録」
5「道具と手順」
6「自動化」
7「参照資料と設計」
画面確かめること
「しくみ」役割と置き場所の地図です。
「概要」起動や会話の始めに読む量と内訳です。
「読み方」起動から会話の終わりまで、いつ何を読むかです。
「比べる」Claude Code と Codex の設定の違いです。
「点検」重なり、一覧の量、使われた記録などです。
「スキル」読むための棚、中身、構成と置き場所です。
「ふりかえり」AI ログの使用量をグラフや表で見ます。
「履歴」2 つの時点を選び、文書や設定の差を見ます。
「書き出し」選んだ範囲を HTML の設計書にまとめます。

一覧から、対応する全 22 種類の本文を開けます。Markdown、行番号付きの原文、見出しの目次、文書の属性の表で読み分けられます。この画面から、設定や文書を書き換えたり、スキルを起動したりはしません。

点検では、現在のアカウントの同期スキルと、ほかのアカウントの控えを区別します。無効や手動専用のスキルは、重なりや一覧の字数から外します。読めない設定は不明、今の設定を当てた一覧の量は推定と表示します。

「履歴」の比較に、記憶の本文は含めません。HTML の書き出しも、記憶、鍵、会話の本文を除きます。除外項目を先に示し、名前の検査に当たると保存を止めます。

鍵らしい値は伏せ字で、選んだ 1 値だけを 15 秒間表示できます。画面を離れると隠し、履歴や書き出しには値を残しません。目録は ~/.mycmux/agent_design/ に保存します。

何にコストがかかったかを見たい#

要点

  • 「エージェント設計」の「ふりかえり」で、期間を選んで使用量を見ます。
  • 作業種別や推移から、個別の会話の内訳へ進めます。
  • 金額はログと単価から出すコスト相当で、請求額ではありません。

「エージェント設計」の「ふりかえり」を開きます。AI ログ分析では、この PC にあるエージェントの記録を検索用にまとめます。この機能は ailog とも呼びます。

画面を開くだけでは、言語モデルを起動しません。日ごとの集計を保存するため、保存済みの集計があれば開いたときにすぐ表示します。最新分は裏で集計し、できた結果へ差し替えます。

Gemini の利用分も、ログに記録されたモデルの単価を使って集計します。

期間は「7日」「30日」「90日」「今年」「全期間」「カスタム」から選びます。円換算のレートは手入力です。「記録は〜まで」「未取り込み」の表示で、集計の範囲を確かめます。

作業の内訳をたどる

上段には期間のサマリーと日ごとの積み上げ棒が並びます。棒を選び、「この日に絞り込む」でその日を調べられます。セッション一覧の「主題」からは、個別の詳細へ進めます。

表示する金額はログと単価から出したコスト相当で、請求額そのものではありません。集計には既知の課題もあるため、欠落や未取り込みを含む参考値として使います。

見る場所分かること
「内訳」作業やモデルごとの内訳です。
「比較」2 つの切り口で比べます。
「セッション」検索、並べ替え、個別の詳細です。
「手戻り」失敗や書き直しを調べます。
「モデル切替」モデルの切り替えを調べます。
「活動時間」曜日と時間帯ごとの活動です。

指標は入出力トークン、総トークン、ターン数、セッション数、コスト相当から選べます。モデル、会社、案件などでまとめ直せます。

「カスタム」の期間は、開始日と終了日の両方を選んで確定します。取り込みをやり直す場合は、上部の「⋮」から「再インデックス（全量）」を選びます。

詳細では、作業フォルダや要約、ターンごとのコスト相当、ツールの実行結果を確かめられます。「会話を読み込む」で本文を読み込みます。

元の記録がないときは、同名の圧縮ファイルや設定した代わりの場所、控えも探します。集計の一部が失敗しても読めた表やグラフを残し、失敗した対象を再試行できます。「このセッションを要約する」は、AI を有効にしているときに使えます。

見た目やキーを変えたい#

要点

  • 「設定 → 外観 → かんたん設定」で、テーマと文字の大きさを選びます。
  • 壁紙や色を細かく変えるときは「詳しく調整する」を開きます。
  • キーは「キーボードショートカット」で割り当て、既定へ戻せます。
設定 13 タブの一覧と、各操作の入口かんたん設定から選ぶ壁紙、配色、描画を調整する右クリックとキー割り当ての操作
設定 13 タブの一覧と、各操作の入口

設定は 5 つの群に分かれ、タブは 13 あります。

群タブ
「表示」「外観」「キャラ」「通知・配置・入力」
「作業」「このPCの履歴から再開」「使うサービス」「ランチャー」「セーブポイント」「AI」「自動化」
「接続」「スマホから使う」
「アカウント」「アカウント・使用量」
「その他」「キーボードショートカット」「アプリ情報」
タブこのタブで決められること
「外観」テーマ、壁紙、文字の大きさ、端末フォント、色です。
「キャラ」ペットの表示、候補、ワークスペースへの割り当てです。
「通知・配置・入力」通知音、トースト、「⋮」の分割項目、入力先と履歴の読み方です。
「このPCの履歴から再開」履歴の検索対象や絞り込み、一覧の表示です。
「使うサービス」エージェントのサービスごとの表示です。記録や使用量は消しません。
「ランチャー」起動項目や「ターミナル」の表示と、開発や案件のフォルダ登録です。
「セーブポイント」保存済みの一覧を開き、記録を受け取ります。
「AI」AI の有効化、使うモデル、各機能、Claude Code スキル、エージェント連携です。
「自動化」見守り、自律モード、気づき、休眠セッションの整理です。
「スマホから使う」「ポケットmycmux」の接続先と QR コードを確かめます。
「アカウント・使用量」ログインの管理、使用量、自動切り替え、単価です。
「キーボードショートカット」キーの割り当てと、既定への戻し方です。
「アプリ情報」版番号と更新の確認です。

新しい切り離しは、Windows と Mac の両方で既定でオンです。「通知・配置・入力」で前の動きへ戻せます。Windows は「タブの切り離しを新しい動きにする (試験中)」です。

Mac は「Macの窓の切り離しを新しい動きにする (試験中)」です。

アプリの更新は、「設定 → アプリ情報 → 更新を確認」で確かめます。新しい版があると右上に青い更新マークが出ます。どちらからも今の版と新しい版の確認枠を開き、「更新して再起動」か「あとで」を選べます。

画面右上のメールアイコンから、改善の要望を送れます。事前に「設定 → アプリ情報 → 改善の要望の送り先」を登録します。種類、機能、内容、急ぎ度などと、窓のスクショを最大 3 枚添えられます。

変えるもの設定の場所
テーマ 30 本「外観 → テーマ → すべてのテーマを表示（30）」。「静かな暗色」「個性の強い暗色」「明るい配色」の 3 つに分かれます。
壁紙 11 枚「外観 → 詳しく調整 → 背景」。選んだときにダウンロードします。
背景の見え方「外観 → 背景の見え方」で「塗りつぶし」「すりガラス」「クリア」の 3 択。細かくはスライダー 5 本で調整します。
端末フォント 10 プリセット（設定画面）「外観 → 端末フォント」
画面の密度と色「外観 → 詳しく調整 → 画面の余白と文字の大きさ」で「つめる」「標準」「ゆったり」。色は「選んだテーマの微調整」に 12 種のプリセットがあります。
キーの割り当て「キーボードショートカット → 変更」でキーを入力します。

Ctrl+,（Mac は Cmd+,）でもショートカット設定を開けます。「戻す」で 1 件ずつ既定に戻せます。全件を戻すときは「既定に戻す」を押します。

かんたん設定から選ぶ#

  1. 「外観」の「かんたん設定」を開きます。
  2. 「塗りつぶし」「すりガラス」「クリア」から、背景の見え方を選びます。
  3. おすすめの「石墨」「極夜」「月白」からテーマを選びます。
  4. 「文字の大きさ」を「小」「中」「大」から選びます。
  5. 端末フォントの見本を見て、読みやすい書体を選びます。
端末フォントの分類選ぶ目安
「コード・標準」普段のコードやログの表示です。
「日本語・表の読みやすさ」日本語の文章や表の読みやすさを見ます。
「印象を変える」教科書体や明朝体を選べます。

設定画面に並ぶ 10 プリセットに、同梱の UDEV Gothic と HackGen Console が含まれます。ボタン、入力欄、知らせ、会話のコードと設定の説明にも、端末フォントが効きます。Markdown の本文と、設定のフォントの見本は別です。

開いていた別の窓は、アプリを開き直すと新しい書体になります。「設定 → アプリ情報 → 同梱フォントのライセンス」で、ライセンスを読めます。

表のプレビューで、数字や罫線の揃い方も確認してください。下の画像は「かんたん設定」の上部と、おすすめの「石墨」「極夜」のカードです。

壁紙、配色、描画を調整する
調整選べること
描画方式通常の描画が合わないときに、方式を切り替えます。
壁紙用意された 11 枚、ローカルの画像、単色です。
背景のスライダー画像の不透明度、ぼかし、壁紙の色調、パネル、ターミナルです。
画面の密度「つめる」「標準」「ゆったり」です。
色の個別変更基本の配色と、端末の文字に使う色（ANSI 色）を調整します。

「塗りつぶし」では、パネルとターミナルの透過調整は使えません。テーマを変えると色の個別調整は戻るため、変更後の表示を確認します。取り消しのトーストから元へ戻せます。

壁紙は「すべて」「暗め」「中間」「明るめ」で絞り、キーワードでも探せます。ローカル画像のパスを使うこともできます。配布物に入れていた 48 枚は、再配布の権利を確かめられなかったため外しました。

同じときに「macOS」「Warp」などの分類での絞り込みもなくなっています。

色を個別に変える

「主要色」は、背景や文字、カーソルなどを 1 色ずつ変える入口です。端末の基本の 16 色（ANSI 色）などは「詳細色」を開いて変えます。

右クリックとキー割り当ての操作#

標準の右クリックメニューは出しません。操作は「⋮」ボタンとドラッグに寄せてあり、右クリックでの選択コピーは使えます。

キーの変更中に Backspace か Delete を押すと、その割り当てを外せます。重複する割り当ては赤く表示されるため、保存後のキーを確かめます。

AI と自動化を止めたい#

要点

  • 「設定 → AI」の親スイッチで、AI を使う機能を止められます。
  • 「自動化」で見守りや通知、自動で片づける時間を選びます。
  • タブの自動命名と通常の再配置は、AI が無効でも使えます。
自動化と、個別設定の項目タブ再配置に Jev を使う

「設定 → AI」の「Claude Code スキル」から、3 つのスキルと委譲 CLI を導入、更新できます。

カードの状態操作
「未導入」「導入」で用意します。
「更新あり」「更新」で配布された内容へ更新します。
「最新」導入済みの内容を使えます。
「ローカル改変」変更内容を確認し、「退避して置き換える」を選びます。

前提は Claude Code と Python 3.10 以上です。導入時に問題があれば、カードの結果と「再確認」を使います。

「設定 → AI」の「エージェント連携」で、Claude Code、Codex、Grok の連携状態を見られます。終了や質問を mycmux に知らせる仕組みを hook と呼びます。必要に応じて「入れる」「直す」「外す」を選べます。

「設定 → AI」の「AI機能を有効にする」が親スイッチです。オフにすると、返信案の準備など、AI を使う機能が止まります。材料から表示名を付ける自動命名は、そのまま使えます。

「設定 → 自動化」では、見守り、自律モード、通知の敏感さ、休眠セッションの整理時間を決めます。

自動化と、個別設定の項目
「自動化」の項目決めること
「見守りを有効にする」委譲した作業の定期確認です。
「通知の敏感さ」「控えめ」「標準」「敏感」などを選びます。
「見守りの通知を出す」確認結果を通知するか決めます。
「休眠セッションの整理」自動整理しないか、30 分、60 分、120 分後かを選びます。
「実行契約の次の作業を自動で始める」自律モードを切り替えます。
「先回りカード (気づき)」以前の気づきカードの仕組みを切り替えます。ダッシュボードの「気づき」列のカードは、この設定では止まりません。

個別設定には、返信案の準備、報告の要約、タブ整理の判定があります。AI ログ分析の要約も個別に切り替えられます。

「タブの自動命名」は、既定でオンです。AI を使わず、案件登録やフォルダ、会話の題名から表示名を付けます。オフにすると、前に付いた自動の名前を外します。

タブの並べ替えは「タブ再配置」から行えます（案の見方）。

タブ再配置に Jev を使う

OpenRouter は、複数の AI を呼び出せる外部サービスです。Jev は、OpenRouter 経由で「役割で見渡す」の役割を判定する機能です。既定は無効で、AI と Jev を両方有効にした場合だけ使います。

無効のままなら、3 つの再配置案は手元の材料だけで作ります。

  1. 「設定 → AI」で「AI機能を有効にする」をオンにします。
  2. Jev の再配置設定で、「OpenRouter APIキー」と「Jevのモデル」を入力します。
  3. 「接続テスト」を押し、結果を確認します。
  4. 「役割で見渡す」の役割判定に Jev を使う項目をオンにし、「Jev設定を保存」を押します。

API キーは、この端末の OS の保護機能で保存します。役割の判定では、タブ名、作業フォルダ、題名、親子関係を OpenRouter 経由で送ります。接続テストは短い確認データを送り、API の利用料が発生します。

案の選び方と適用後の確認は、タブをまとめ直すにあります。

スマホやキャラクターを使いたい#

要点

  • 「設定 → スマホから使う」で、配信済みの接続先を確かめます。
  • QR はスマホのブラウザで開く入口で、iPhone アプリを直接開きません。
  • Buddy やペットの表示は「キャラ」で選び、表示しない形も使えます。
スマホから開くBuddy とペット

スマホからの接続と、デスクトップのキャラクターの設定です。

スマホから開く#

「設定 → スマホから使う」で、「ポケットmycmux」の接続先を確かめます。iPhone 用のアプリと入手の状況は、ポケットにまとめています。

Tailscale は、離れた PC とスマホをつなぐためのサービスです。QR コードと URL が出るのは、Tailscale の tailscale serve で /pocket を配信しているときだけです。設定を開くたびに接続先を調べるので、ホスト名が変わっても新しい URL を表示します。

配信中でも応答がない場合は、URL の下に注意書きが出ます。

  1. PC 側で「ポケットmycmux」のサーバと、Tailscale の配信を用意します。
  2. 「設定 → スマホから使う」を開き、QR コードと注意書きを確かめます。
  3. スマホで QR コードを読み、ブラウザで「ポケットmycmux」を開きます。

現在、QR コードから iPhone アプリが直接起動することはありません。QR が出ない場合は、「ポケットmycmux」のサーバと配信の設定を確かめてください。

mycmux 内蔵のモバイル画面と、その接続用サーバはなくなりました。リモート接続の有効化、LAN 公開、接続中端末の一覧、トークンの再生成もありません。以前の接続設定は読み飛ばすため、設定ファイルを手で直す必要はありません。

Buddy とペット

Buddy は、エージェントの活動に合わせて発話するデスクトップのキャラクターです。標準ビルド（配布版）では、既定の顔を表示します。

新しく入れたときは、キャラを表示しない状態（「キャラなし」）から始まります。以前の版から使っている場合は、保存されている選択がそのまま残ります。

ワークスペースのペットは「設定 → キャラ」で選びます。ワークスペースに 1 体出すか、表示しないかの 2 択です。「変更 ▸」で割り当てを変え、「今すぐ再スキャン」で追加したペットを読み直します。

同じ窓で使っているキャラを避ける抽選が既定です。候補を使い切ると再び抽選し、残りは保存して再起動後も引き継ぎます。既存の割り当ては保ち、以前のランダム方式へ戻すこともできます。

ペットは候補に入れるものを選び、ワークスペースに固定するか、候補から選ぶかを決められます。「ギャラリー」で絵柄を確かめ、隔離したものは戻せます。
