画面と操作

ワークスペースの分け方、エージェントの起動、端末の出力の読み方、成果物の開き方をまとめました。委譲やダッシュボードはエージェントとの作業に、テーマやキーの変更はアカウントと設定にあります。

キーは Windows の既定を先に書き、違うものは Mac のキーも添えています。Ctrl と Tab による切り替えは、両方の OS で同じです。

作業場所を分けたい#

ワークスペースを作る番号でワークスペースへ移る

案件や調査ごとに分ける作業場がワークスペースです。端末の会話、Web、資料などの画面 1 つをタブと呼びます。タブを並べるために画面を割った場所が表示場所です。

同じ表示場所には、複数のタブを重ねて置けます。表示中のタブを替えても、裏の端末の作業は続きます。

ワークスペースを作る#

したいこと操作
すぐに作るCtrl+Shift+N。現在の作業フォルダを引き継ぎます。
エージェントや配置も選ぶCtrl+Shift+Alt+N
次の作業場へ移るCtrl+Tab。前へ戻るときは Shift も押します。

Mac で作るときは、Ctrl を Cmd に読み替えます。切り替えは、両方の OS で Ctrl+Tab です。

サイドバーの行をダブルクリックすると、ワークスペース名を変えられます。行の「⋮」では色の変更と「新しいウィンドウで開く」を選べます。行をドラッグすると並び順が変わります。

色は 8 色と色なしから選べます。サイドバーの幅は、境界をドラッグして 200〜560px に変えられます。作成時の配置は 8 種類で、既定は 3×1 です。

番号でワークスペースへ移る

Windows は Ctrl、Mac は Cmd と 1〜8 の数字キーを押します。9 を押すと、最後のワークスペースへ移ります。

タブを並べ、切り替えたい#

大きさと境界を変える名前、固定と狭い表示タブの名前が付くしくみマウスを乗せて入力先を変える

見出しには、表示中のタブの名前と「裏 N」が出ます。狭いときは「+N」になり、押すと同じ場所のタブ一覧が開きます。一覧でタブを選び、名前の変更、並びの先頭への固定、終了もできます。

したいこと操作
同じ場所にタブを足す見出しの「⋮」から「新しいターミナルタブ」を選びます。
裏のタブへ切り替える「裏 N」を押して、一覧から選びます。
右や下に並べる見出しの「右にタブを開く」を押します。下に開く操作と、狭い表示では「⋮」から選びます。
ひとつに集中するCtrl+Shift+Enter。もう一度押すと元へ戻ります。
表示中のタブを閉じる名前のすぐ右の「×」か Ctrl+Alt+W
閉じたタブを開き直すCtrl+Shift+T

右に開くキーは、Windows では Ctrl+Alt+D です。Mac では Cmd+D です。Shift も押すと、下に開きます。

見出しの分割ボタンは、既定では「右にタブを開く」だけが出ます。「設定 → 通知・配置・入力」で「下にタブを開く」も表示できます。「このタブだけ表示」の最中に分割すると、拡大を解いて新しいタブを見せます。

名前のすぐ右の「×」は、表示中のタブだけを閉じ、裏のタブは残します。

見出しの右端の「×」は、裏のタブも含めて同じ表示場所を閉じます。右端の「×」は裏のタブがあるときだけ出て、狭い表示では出ません。狭いときは「⋮」の「このタブと裏のタブ N 個を閉じる」を使います。この操作で開き直せるのは、表示中だった 1 つだけです。

作業中のタブには、閉じる前に確認が出ます。最後の表示場所を空にする操作は、理由を示して押せなくなります。

大きさと境界を変える

境界線をドラッグすると、表示場所の幅や高さを変えられます。手で動かした線だけが位置を覚えます。別の場所を分割しても、手で広げた幅は変わりません。

境界線をダブルクリックすると、同じ並びを均等に戻せます。「このタブだけ表示」で拡大しても、裏の作業は続きます。

名前、固定と狭い表示

名前の変更は「⋮」かタブ一覧から行います。「名前を自動に戻す」で、自動命名へ戻せます。Ctrl+Alt+P で、表示中のタブを並びの先頭に固定します。

細い表示でも「×」と「⋮」は残ります。裏のタブのエラーや返事待ちは、「裏 N」の色でも分かります。

タブの名前が付くしくみ

Claude Code では会話の題名を使い、手で付けた題名があればそちらを優先します。題名がないタブは、指示から分かる作業名、それもなければ起動時の名前を使います。材料がなければ「作業内容未取得」と、取れない理由を短く表示します。

自分で付けた名前は変えません。命名に AI のモデルは使いません。

名前は 20 字までで、同じ名前が並ぶときだけ番号を添えます。題名の頭が、手で付けたワークスペース名と同じなら、その部分を省きます。ワークスペースの自動名には、会話の題名と指示からの名前を使い、起動時の名前は数えません。

材料を一時的に読めなくなったら、最後の名前を「前回」の印つきで約 30 分残します。別のタブの名前を拾わないよう、そのタブのものと確認できた材料だけを使います。依頼を中断したり別の依頼に替えたりした後は、前の作業名を使いません。「続けて」など、続きだと確認できる入力では名前を保ちます。

「設定 → AI」で自動命名を切り替えられます。

マウスを乗せて入力先を変える

「設定 → 通知・配置・入力」の「タブのフォーカス」で選べます。既定はクリックで、「マウスを乗せたら切り替える」も使えます。端末やランチャーの本文に約 100 ms 留まると、その入力先へ切り替わります。

編集中、変換中、メニューやダイアログの表示中、ドラッグ中は切り替わりません。文字を選択している間や、窓が非アクティブな間も切り替わりません。Web、オンライン、休止中のタブも対象外です。起動メニューから端末へ戻るときは、クリックしてください。

プレビューや Web の見出しを触ると、そのタブが閉じるキーの対象になります。HTML プレビューと Web の本文だけを押した場合は、まだこの切り替えの対象外です。

タブをまとめ直したい#

ダッシュボードの配置図から「タブ再配置」を開きます。配置を確認して適用でき、適用後は「元に戻す」で取り消せます。

切り口まとめ方
「今の場所に寄せる」移動を抑えます。
「案件ごとに分ける」同じ案件の作業をまとめます。
「役割で見渡す」作業の役割で分けます。
「稼働中だけ」見張る必要があるタブを集めます。
「メインだけ」主に相手にしている最大 3 本を集めます。
「属性でまとめる」案件を基本に、タブの少ない似た案件をまとめます。

AI の案を待たず、内容を確かめて適用できます。「稼働中だけ」「メインだけ」は、同名のワークスペースがあればそこへまとめます。選んだ切り口を覚え、同名のワークスペースを増やしません。

「属性でまとめる」は、タブの少ない案件を、近い属性どうし 2〜3 件でまとめます。属性は「編集・制作」「アプリ・開発」「整理・事務」です。AI がオフでも、登録情報から案件を確定できるタブで案を作ります。

判定できない案件を推測でまとめず、名前も変えません。初めのプリセットは従来どおりで、「属性でまとめる」は選んだときに使います。

AI に役割の判定を補わせる Jev は、既定ではオフです。設定と送る情報は、Jev の説明にまとめています。

閉じる候補は「タブ掃除」で、名前、判定、理由を確認します。キャンセルすると閉じず、AI が使えない場合も終了済みの候補を確認できます。休止はプロセスを終える操作で、途中の実行状態は戻りません。

休止候補は、作業中、権限待ち、質問待ちを保護します。完了だけが未読なら、会話の保存を確認してから休止できます。ただし休止候補と「稼働中だけ」は、ダッシュボードの新しい作業中判定とは別です。

長い道具や見張りが動く裏のタブも、休止時間が来ると止まる場合があります。自動休止を使う前に、休止の設定を確かめてください。

タブを窓に切り離したい#

窓にして、戻す戻す場所と目印切り離した窓の帯を操作するしおりから引き継ぐうまく戻らなかったとき再起動のあと切り離しの動きを設定する

タブの見出しを外へ引くと、その場で窓になり、押したままカーソルについてきます。端末は起動し直さず、作業を続けたまま移ります。Windows と Mac の両方で、この動きが既定です。

画面の倍率が違う場合や画面をまたぐ場合に、つかんだ位置と窓がずれる問題を修正しています。

窓にして、戻す#

  1. タブの見出しをつかみ、表示場所の外へ引きます。
  2. 好きな位置で離します。アプリの窓の上でも、いったん別の窓になります。
  3. 戻すときは窓の帯をつかみ、mycmux に重ねます。
  4. 入る位置の枠や破線を確かめて離します。Esc で移動前へ戻せます。

見出しの空いた所をつかむと、裏のタブごと運べます。ワークスペースごと運ぶときは、サイドバーの行をつかみます。端末、HTML、Office、PDF、Web と、未起動のタブも対象です。

戻す場所と目印
離す場所結果
表示場所の見出し同じ場所に加わり、そのタブを表示します。
表示場所の端分割して隣に並べます。
サイドバーのワークスペース名約 0.35 秒留まると、その作業場が開きます。
表示場所の中央タブとして合流し、落としたタブを表示します。先頭に固定したタブの並びは保ちます。
サイドバーの新規作成部分新しいワークスペースとして置きます。

ほかの mycmux の窓にも戻せます。受け皿だけの窓は、サイドバーの「新しいウィンドウ」から開きます。要求が始まる前に断られた場合は、黄色の案内で知らせます。

切り離した窓の帯を操作する#

操作Windows Mac
最小化帯のボタンで畳みます。新しい切り離しの帯にはありません。
最大化と元に戻すボタンか帯のダブルクリックです。新しい切り離しの帯にはありません。
閉じる窓のタブを終了します。作業中なら確認が出ます。同じく、窓のタブを終了します。

Windows 11 では、最大化ボタンに乗せると OS の配置候補が出ます。閉じる操作は作業を終了するため、戻すときは帯をつかんで運びます。

しおりから引き継ぐ#

文脈を別のエージェントへ渡すときは、しおりと、しおりからのドラッグを使います。タブや窓を表示場所の中央に落としたときは、引き継ぎを出さずタブとして合流します。

うまく戻らなかったとき

通知の「付け直しをやり直す」から、端末表示の回復を確かめます。「切り離しをやり直す」が出た場合は、戻せてから再試行できます。通知に出たタブ名と場所を確かめてください。

再起動のあと

開いていた窓のまとまり、位置、大きさを戻します。Windows では最大化の状態も戻り、画面外の窓は見える位置へ移します。ほかの窓を残して閉じた窓の作業は、次の起動では戻りません。

切り離しの動きを設定する

「設定 → 通知・配置・入力」で切り替えます。Windows は「タブの切り離しを新しい動きにする (試験中)」です。Mac は「Macの窓の切り離しを新しい動きにする (試験中)」です。

どちらも既定はオンです。オフでは、アプリの外まで運んで離した後に別の窓が開きます。Mac のオフでは、OS 標準の枠を持つ窓になります。

タイトルバーの入口を知りたい#

左側には、サイドバーの開閉、セーブポイント一覧、ワークスペース作成の入口があります。中央はワークスペース名です。右側は次の 4 つで、Windows ではさらに窓の操作が並びます。

入口開くもの
「アカウントと使用量」アカウント一覧と使用量です。
「エージェント設計」設定、指示、記憶やスキルを読む画面です。
「ダッシュボード」全ワークスペースの会話と状態です。
「設定」アプリの設定です。

上の帯に受け取り箱のボタンはありません。外部報告は、届いた通知の「開く」から確認します。

AI ログ分析とスキルは、エージェント設計の中から開きます。AI ログは「ふりかえり」を選んだときに読み込みます。使用量の帯の「CC」「CX」「GK」は、Claude Code、Codex、Grok Build です。

エージェントを起動したい#

要点

  • 新しいタブのランチャーで、エージェントのアイコンを選びます。
  • 「…」からモデルと effort（考える深さ）を選んで起動します。
  • Web のサービスや登録フォルダ、過去の会話からも始められます。
モデルと effort を選ぶ普通のターミナルから始めるWeb サービスを横に置く開発や案件のフォルダを登録する過去の続きから開く

新しいタブに出る起動メニューがランチャーです。「新規に起動」「Web」「開発」「案件」が並び、履歴があれば「続きから」も出ます。項目をクリックするか、検索欄に名前を打って選びます。

対応するエージェントは 8 種です。「Claude Code」「Codex」「claude-codex」「Grok」「agy」に対応します。「Hermes」「Oh My Pi」「Cursor」も選べます。表示する項目は「設定 → 作業 → 使うサービス」で選べます。

「Grok」は Grok Build を、「agy」は Antigravity の CLI です。

Claude Code、Codex、Grok は、ランチャーや新しいワークスペースの「アカウント」でタブごとに選べます。指定したアカウントは、アプリ再起動後の復元にも使われます。使えない場合は別のアカウントへ勝手に切り替えず、理由を示します。

未登録のものも「タブでも使う」から、その場で登録を始められます。タブの名札と ⋮ の「このタブのアカウント」で確認状態や使用量を見られます。

claude-codex のモデルは、この 1 行から選びます。

claude-codex から新しく起動したタブは、青い Claude Codex の印で見分けられます。

導入済みの Grok Bot を開く「Grok Bot (アプリ)」の入口もあります。

Claude Code、Codex、claude-codex、Grok Build の 4 種は、ランチャーと状態の表示で同じ扱いです。agy、Hermes、Oh My Pi は新規起動できますが、会話の再開や引き継ぎには対応しません。

Cursor は cursor-agent を別に入れ、「Cursor」から起動します。「…」で Composer 2.5 などのモデルを選べます。Cursor に独立した effort の項目はありません。会話の復元には対応せず、mycmux を再起動すると起動メニューに戻ります。

キーボードでは ↑↓ で選び、Enter で決めます。Esc は検索語を消します。エージェントを選んで Tab か Shift+Enter を押すと、モデル選択へ進みます。

モデルと effort を選ぶ#

effort は、考える深さを指定する設定です。「モデル」「effort」を選び、「起動」を押します。←→ で値を変え、↑↓ か Tab で項目を移ります。

「既定」のままなら、CLI の既定値で起動します。

claude-codex のモデルは、パネルを開くたびに claude-codex の設定から読み込みます。設定で足したモデルも、そのまま並びます。

区分並ぶもの
「新規に起動」設定で表示したエージェントや「ターミナル」から始めます。
「Web」ChatGPT、Gemini、Grok、Claude.ai、NotebookLM、Browser、ChatGPT dots です。
「開発」登録した開発用フォルダです。
「案件」登録した案件用フォルダです。
「続きから」履歴から再開する候補です。設定で表示を切り替えます。

Grok Build も、ランチャーの一覧からモデルを選べます。Hermes にはモデルと effort の行がありません。使うモデルは Hermes 側の設定に従います。

普通のターミナルから始める#

「新規に起動」の最後にある「ターミナル」を選ぶと、シェルが開きます。ここで claude や codex と入力しても、mycmux の連携付きで起動します。項目は「設定 → ランチャー」で隠せます。

検索欄にコマンドを入力し、候補の最後の「ターミナルで実行」を選ぶ方法もあります。新しいターミナルへ 1 回だけ流し、再起動してタブが戻っても流し直しません。起動用の入力は保存しません。

入力は改行や制御文字のない 1 行にします。長さの上限は 4,096 文字分で、一部の文字は 2 文字分に数えます。実行する内容を確かめてから選んでください。

Web サービスを横に置く#

「Web」には 7 つの項目が並びます。6 つの Web サービスと、任意のページを開く Browser です。サービスは ChatGPT、Gemini、Grok、Claude.ai、NotebookLM、ChatGPT dots です。

端末の横で調べ物や資料を確かめるための入口です。ログインが途中で止まるときは、表示される「別の窓でログイン」を使います。

ChatGPT、Gemini、Claude.ai、NotebookLM は、Google ログインの保存先を共有します。ChatGPT dots も、同じ保存先を使います。Grok は X のログインなので別です。

「別の窓でログイン」で開いた窓を閉じると、Web タブが開き直ります。

外部サイトの Web タブからは、端末やファイル、設定、更新、窓の操作を呼べません。ただし本体あてのデータの一部を読める経路は残ります。信頼できないサイトは Web タブで開かないでください。

Web タブで落としたファイルは ~/.mycmux/handoff/web/ の下に受け取ります。同じ名前のファイルは -2、-3 と番号が付きます。

開発や案件のフォルダを登録する

「設定 → ランチャー → フォルダを選んで登録…」で、作業フォルダを登録します。ランチャーの「開発」「案件」からフォルダを選び、その後にエージェントを起動します。現在の起動先の表示は、ランチャーの下部です。

「候補」に出たフォルダは、「開発に登録」「案件に登録」で追加できます。初期設定の自動ルールは候補を出すだけで、登録行を勝手には増やしません。

ランチャーの項目を自分で足すには、~/.mycmux/bin/launcher.local.ps1（macOS は launcher.local.sh）に書きます。このファイルはアプリの更新で上書きされません。ランチャー項目の全一覧は、README（付録 B）にあります。

一覧操作と並び方
手動の登録行表示名を変え、「↑」「↓」で順番を変えます。
自動の登録行新しい順です。「固定」で手動の行に移せます。
「候補」「開発に登録」「案件に登録」で、選んだ分だけ登録します。
「無視」次の走査から、同じ場所を候補に出さないようにします。

自動登録には、git リポジトリ、ファイル更新、動かした場所、セッションで触れた場所の 4 種があります。ルールごとに「候補にする」か「自動で登録する」を選びます。「今すぐ走査」でも更新できます。

設定の正本は ~/.mycmux/launch-dirs.json です。

従来の launch-roots.txt は、アプリが書き出すファイルです。

同じ設定画面の上部で、ランチャーに出す項目を切り替えます。その下に「開発」「案件」の「フォルダを選んで登録…」があります。

過去の続きから開く

ランチャーの「続きから」は、直近の会話を開く入口です。広く探すなら、Ctrl+P（Mac は Cmd+P）の Resume を使います。どちらも、アプリに保存された会話の一覧を使います。

使い方は、エージェントとの作業の「過去の会話を選ぶ」にあります。

ターミナルの出力をたどりたい#

要点

  • 出力中のファイルパスを押すと、成果物を開けます。
  • ターンチップから、前に送った指示と会話をたどれます。
  • 長い指示は下の入力欄に書き、Enter で送ります。
会話の表示と端末の表示ファイルパスを開く送った指示まで戻る会話の全過去を読む長い指示を書くコピー、貼り付け、拡大エージェントの状態と入力待ち

端末の出力から、成果物を開く、送った指示へ戻る、文字を探す、長い指示を書く操作です。

端末の表示履歴は 5,000 行です。プロセスが終了すると、終了を示す文字と再起動ボタンが出ます。出力はディスクにも保存します。

終了済みのセッションは保存済みの出力を、生きているセッションは現在の出力を取り直して表示します。

会話の表示と端末の表示#

エージェントのタブは、見出しのアイコンから「会話の表示」と「端末の表示」を切り替えられます。既定は会話の表示で、設定の「通知・配置・入力」で端末の表示にも変えられます。

会話の表示の下には端末の最新行が出ます。Claude Code と Codex は会話内を検索できます。

Claude の入力欄では / から候補を選べます。会話履歴は「⋮」から開き、端末の表示に切り替わります。Ctrl+P はセッションを続きから開くキーで、このタブの会話履歴を開く操作とは別です。

ファイルパスを開く#

出力の中にある実在するファイルやフォルダは、そのままリンクです。日本語や空白を含むパスも、途中で折り返されたパスも対象です。クリックすると、対応する文書はプレビューで開き、それ以外は開き方を選べます。

送った指示まで戻る#

端末の出力を遡ると、指示の位置へ戻るターンチップが出ます。「▲」「▼」で前後の指示へ移れます。指示の一覧は新しい順で最大 200 件です。

会話の全過去を読む#

Claude Code と Codex は、会話の記録から作った履歴画面で読めます。端末の表示で上へホイールを回すか、「⋮」の「会話履歴を開く」から開きます。「最初へ」「最新へ」と、前後の指示へ移るボタンが使えます。

会話の全過去は、ページごとに読み込みます。検索は新しい発言から探し、「次へ」で古い方へ進みます。1,000 件に達すると数えるのを止め、「1,000 件以上」と表示します。

数えている途中は「ここまでで N 件」です。「止める」で止め、「もう一度検索」で追加された発言も探せます。長い本文の続きと、道具の呼び出しや出力は検索の対象外です。

日本語の変換中は検索せず、確定の Enter で次へ進みません。検索欄に打った文字は端末に入らず、閉じると端末へ戻れます。

会話の表示では検索操作が会話内を探し、端末の表示では端末内を探します。Grok の会話の表示では、端末の表示に切り替えてから端末内を検索します。「設定 → 通知・配置・入力」で、履歴への入り方を変えられます。

Shift とホイールでは、端末の表示履歴を読みます。変換中、文字の選択中、質問や承認待ちでも、通常の端末スクロールです。端末内の検索は「⋮」か Ctrl+Shift+F です。

長い指示を書く#

タブ下の専用入力欄へは Ctrl+Alt+I（Mac は Alt+Cmd+I）で移ります。Enter で送信、Shift+Enter で改行です。日本語の変換を確定しただけでは送信しません。

入力欄の表示は「設定 → 通知・配置・入力 → タブの下に入力欄を出す」で切り替えます。

「Claude メッセージを入力」などの専用入力欄には、最大 10 万文字を書けます。タブが低くなると自動で隠れるため、見えないときはタブの高さを広げます。シェルへ送る複数行は、1 行にまとめて渡します。

作業中のタブを閉じる前に、アプリの中で確認が出ます。

コピー、貼り付け、拡大

端末の基本操作は次のとおりです。

したいこと操作
選んだ文字をコピーするドラッグで選んで離すと、自動でコピーします（3 文字未満は対象外）。
貼り付けるCtrl+V（Mac は Cmd+V）で貼り付けます。長い文は 1024 文字ごとに分けて送ります。
エージェントへ改行だけ送るShift+Enter
端末の文字を拡大縮小するCtrl を押しながらマウスホイールを回します。ウィンドウ全体に効きます。
出力中の URL を開くクリックします。
日本語を入力するIME の変換中はそのまま端末へ渡し、確定の Enter だけでは送信しません。

Claude Code と Codex では、上へホイールを回すと会話履歴に入ります。Shift を押しながらホイールを回すと、端末の表示履歴を動かします。

エージェントの状態と入力待ち

タブのアイコンは、いま動いているエージェントを表します。エージェントが終了すると、そのアイコンは消えます。

タブには状態ドットと、「作業中」「入力待ち」などのラベルが出ます。出力が静かなだけの状態を、完成と取り違えないための表示です。作業が終わったかを確かめる方法は、エージェントとの作業の「終わったかを確かめる」にあります。

ラベル確かめること
「作業中」作業の出力を追います。
「入力待ち」返事や承認が必要か、会話を開きます。
「未確認の枠切れ」使用量の枠と、再開できる時刻を確かめます。
「未確認の入力待ち」まだ見ていない質問や承認を確かめます。
「未確認のエラー」エラーの内容を開いて確かめます。

通常の待機ではラベルが空になる場合もあります。

成果物をプレビューして直したい#

要点

  • 端末のパスから、会話の隣に成果物を開きます。
  • 鉛筆のボタンから対応する文書を編集し、元のファイルに保存できます。
  • Windows の HTML では、箇所の画像とコメントを添えた指摘を作れます。
プレビューからリンクを開くテキストやログを読むHTML のグラフや画像を見るHTML の画面から指摘を作るWord と PowerPoint の画像リンク画像の読み込みExcel の画像とグラフプレビューと編集のボタン

ターミナルのパスリンクから、その場で成果物を開きます。

形式対応する拡張子
Markdown md、markdown
HTML html、htm
Word doc、docx、docm、dot、dotx、dotm
Excel xls、xlsx、xlsm、xlsb、xlt、xltx、xltm
PowerPoint ppt、pptx、pptm、pot、potx、potm、pps、ppsx、ppsm
PDF pdf（読むだけ・編集はできません）
テキストとログtxt、log、text（読むだけ）

開いた文書のタブには、形式ごとの印が付きます。エージェントのタブに付いている印と同じ場所なので、並んでいても種類が分かります。

編集の入口は、プレビューの鉛筆のボタン（画面の表記は「この文書を編集」）です。HTML と docx、docm、dotx、dotm に対応し、Ctrl+S（Mac は Cmd+S）で元のファイルへ保存します。Markdown は生のテキストとして編集します。

Word の旧形式、Excel、PowerPoint は、アプリ内編集の対象外です。

プレビューで開けない文書は、OS の既定アプリで開く経路へ戻ります。

Markdown は、記号のままではなく本来の形で描きます。表、太字、斜体、インラインコード、番号付きリスト、入れ子、引用、チェックリスト、脚注、画像、水平線に対応します。紙の色は選んでいるテーマに合わせて変わり、狭いタブでは表が 1 行ずつのカードに組み替わります。

プレビューからリンクを開く#

Markdown とテキストのプレビューでは、対応するローカル文書を mycmux の中で開けます。HTML では、ファイルやフォルダのリンクは OS のファイル管理画面で開きます。

リンクMarkdownプレーンテキストHTML
http、https OS の既定ブラウザへ渡します。OS の既定ブラウザへ渡します。OS の既定ブラウザへ渡します。
mailto対応しません。対応しません。対応しません。
文書の中のリンク対象の見出しへ移ります。見出しを解釈しないため、見出しへのリンクは作りません。文書内に指定先があれば移ります。
対応するローカル文書mycmux のプレビューで開きます。絶対パスを mycmux のプレビューで開きます。OS のファイル管理画面で場所を表示します。
そのほかのファイルやフォルダOS のファイル管理画面で場所を表示します。絶対パスの場所を OS のファイル管理画面で表示します。OS のファイル管理画面で場所を表示します。
テキストやログを読む

txt、log、text は、等幅の文字を 80 桁の 1 段組みで表示します。文字コードは BOM、UTF-8、Shift_JIS の順に判定し、UTF-8 以外なら上部に知らせます。文字コードを変えて書き戻すのを避けるため、アプリ内での編集と保存はできません。

本文の Web の URL と絶対パスは、クリックして開けるリンクです。相対パスはリンクにしません。パスの後ろに行番号が付いていても、開くのはファイルだけです。

制御文字や端末の色指定は除いて表示します。5 MB または 50,000 行を超える場合は、先頭の範囲と省略内容を表示します。バイナリ形式のファイルは開かず、理由を知らせます。

macOS でも、HTML の閉じタグをファイルへのリンクと取り違えずに読めます。

HTML のグラフや画像を見る

HTML のプレビューは、タブに重ねた専用の表示画面で開きます。重い文書も、端末の出力と分けて表示します。文書の JavaScript が動くので、グラフや切り替えのある HTML も表示できます。

相対パスで置いた画像も表示できます。タブを切り替えて戻っても、読んでいた位置はそのままです。

このプレビューで開けるのは、成果物の置き場にある文書です。外部リンクは OS の既定ブラウザで開き、ログイン画面はプレビュー内では開けません。保存領域も、ほかの Web サービスとは分かれています。

鉛筆ボタンを押すと、その文書を編集する画面へ切り替わります。編集の入口は、上で説明した「この文書を編集」です。

再表示とページの移動

同じファイルを開き直しても、更新されていなければ読み直しません。読んでいた位置も残ります。

Markdown とテキスト内の対応する文書リンクは、アプリのプレビューで開きます。HTML 内のファイルやフォルダのリンクは OS のファイル管理画面、外部の Web リンクは既定ブラウザで開きます。

HTML の画面から指摘を作る#

Windows のローカル HTML プレビューで「指摘を作る」を開きます。箇所の画像とコメントを添えた依頼文を作り、担当の AI へ自分で貼り付けます。

箇所の選び方操作
「文字で探す」本文にある文字を入力して、候補から箇所を選びます。
「選んだ範囲で指摘」プレビューの文字をドラッグして選んだ範囲を使います。
「画面で選ぶ」図や写真などにポインターを乗せ、対象をクリックします。Esc で取り消せます。

箇所を選び、「修正してほしいこと」を書いて依頼文をコピーします。依頼文には原文、前後の文、直前の見出し、元のファイルと画像の保存先が入ります。担当の AI に貼り付け、現在のファイルと照合してから直してもらいます。

画面や選んだ箇所が変わると、古い画像のままコピーできません。案内に従って箇所を選び直してください。

Word と PowerPoint の画像

Office 文書は、暗いテーマでも白い紙の見た目で表示します。

Word と PowerPoint では、文書に埋め込まれた画像を表示します。この PC 内のファイルを指すリンク画像も対象です。対応しない画像形式や見つからない画像は、表示できない理由を残します。

Web 上の画像は自動で取りに行かず、参照先のホスト名を表示します。必要な画像は、Word などの元のアプリで確認してください。

図の中の文字は、本文へ混ぜずに図の一部として扱います。

リンク画像の読み込み

リンク先のローカル画像は、拡張子だけでなく中身が画像かも確認してから読み込みます。

Excel の画像とグラフ

Excel の画像は、セルの位置を再現せず、表の後ろにまとめて並べます。図に説明文があれば、代替テキストとして保持します。グラフは画像ではないため、このプレビューには表示しません。
