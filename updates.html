v0.74.0

macOS での使い勝手をそろえた版です。

  • 閉じるボタンと ⌘W は、メインの窓を隠すだけになりました。タブは動き続け、Dock のアイコンから戻せます。終了はアプリのメニューの終了（⌘Q）で、開いていた窓と作業を保存してから終わります。
  • 切り離していた窓は、次に起動したとき同じ位置に窓として戻ります。
  • ⌘ のショートカットが効くようになりました。Control はターミナルの中のシェルへそのまま渡ります。画面の分割は ⌘D と ⇧⌘D です。
  • 「続きから」の一覧と ⌘P のパレットが空のままだった問題を直しました。
  • 切り離した窓を、標準の枠を持つ窓として作るようにしました。窓を整えるアプリから掴めます。
  • ⌘Tab などで窓が裏に回ったあと、戻ったときに固まる問題を直しました。裏にいる間も出力を受け取り続け、戻ったらフォーカスのあるタブから描き直します。
  • 何もしていないときに回り続けていた処理を止めました。
  • 深い日本語のパスから Claude の会話を再開できなかった問題を直しました。
  • ランチャーの claude-codex を 1 行にまとめ、モデルは claude-codex の設定から読んで選べるようにしました。

v0.73.0

Markdown のプレビューを入れ替えた版です。

  • 表・太字・インラインコード・番号付きリスト・引用・チェックリスト・脚注・画像が、記号のままではなく本来の形で出ます。
  • 紙の色がテーマに追従します。狭いタブでは、表が 1 行ずつのカードに組み替わります。
  • プレビューの中のリンクが効くようになりました。見出しへの移動、既定のブラウザ、アプリ内のプレビューに分かれます。

v0.72

  • v0.72.0 では、切り離した窓が Windows のスナップに乗るようになりました。ペインをドラッグしたときの落とし先も、実際の大きさで出ます。
  • v0.72.1 では、委譲の CLI やソケットから起動できる相手が、ランチャーの並びと同じになりました。モデルと effort も渡せます。
  • v0.72.2 では、タブを分割したあとの幅と高さが、手で合わせた位置を覚えるようになりました。

v0.71.0

この版の中心は、ペインを窓ごと切り離す機能です。

ペイン 1 つを、中身だけの窓に切り離す

ペインをウィンドウの外へドラッグすると、そのペインだけが入った小さな窓になります。窓にはサイドバーもタイトルバーもなく、上端の細い帯と中身だけです。セッションは起動し直さないので、動いているエージェントは止まりません。

帯をつかんでウィンドウ内のペインバーへ運ぶと、差し込み位置の印が出ます。その位置で離すと、ペインとして戻せます。

帯の「×」は、そのペインを閉じます。ターミナルだけでなく、HTML、Office、PDF、Web のペインも同じ操作で切り離せます。

落とす場所戻り方
ペインバーの差し込み位置その位置へペインを入れます。
タブの中央そのタブのペインに加えます。
タブの端分割して並べます。
サイドバーの新規作成部分新しいワークスペースとして置きます。

サイドバーの「新しいウィンドウ」から、受け皿の窓を開けます。

切り離したペインは、元の窓だけでなく、サイドバーのある別の窓へも入れられます。

窓を閉じると、その窓にある作業を終了します。別の窓の作業は続くため、移す操作と閉じる操作を区別してください。

PDF をアプリの中で開く

ターミナルに出た PDF のパスを押すと、ほかの文書と同じようにペインで開きます。PDF 専用の閲覧画面で表示します。編集はできません。

ペインに文書の形式の印

HTML、Markdown、Office、PDF を開いたペインに、形式ごとの印が付きます。エージェントのペインに付いている印と同じ場所です。

委譲 CLI でワークスペースを片づける

委譲 CLI に workspace-close が加わります。エージェントが裏で作ったワークスペースを、表示中の画面を動かさずに閉じられます。

workspace-close --workspace <id> は、表示中のワークスペースを閉じようとすると拒否します。対象の端末は終了するため、作業の完了を確かめてから使います。

新規作成した場所に最初のエージェントを起動するときは、未使用のランチャーを置き換えます。不要な起動メニューを残しません。

--target shell は、文字の起動メニューを経由せずシェルを開くように直します。

テーマの説明文

30 本のテーマの説明を、背景色と差し色、使う場面が分かる文に改めます。一覧には、30 本すべての配色と説明が付いています。下の画像は「静かな暗色」の見出しと、その最初の 4 枚です。「静かな暗色」「個性の強い暗色」「明るい配色」の 3 つに分かれています。

白系テーマの文字

白系テーマで、通常の端末文字が背景に埋もれないよう補正します。壁紙を見せる背景でも、文字の濃さを補います。

エージェントが薄く表示する dim の文字にも、別の補正を入れます。現行版の月白の画面で薄かった補助文字を、読みやすくする変更です。

使用量の取得と再開時の設定

Grok の使用量取得で、対応していない応答に対して再試行を繰り返す問題を直します。この場合は、アプリを再起動するまで自動の再取得を止めます。

Claude Code を起動する経路の権限指定を auto にそろえます。保存済みのモデルと effort を、再開や復元に失敗した後の新規起動でも引き継ぎます。

会話を復元できないときは、その旨を端末に出してから新しい会話を始めます。

Windows でバックアップなどの保存先が長くなると、書き込みに失敗する問題を直します。

呼び方の整理

画面の文言で、端末の区画と端末そのものの呼び方が、場所によって逆になっていました。この版でそろえ、このサイトの用語も合わせてあります。
