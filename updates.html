最近の変更

しばらく使っていなかった方に向けて、操作に関わる変更をまとめています。更新は「設定 → アプリ情報 → 更新を確認」から行えます（更新の手順）。

画面を分けて使う#

ペインをウィンドウの外へドラッグすると、そのペインだけが入った窓になります。セッションは起動し直さないので、動いているエージェントは止まりません。帯をつかんでペインバーへ運べば、元のペインとして戻せます。

ターミナルのほか、HTML、Office、PDF、Web のペインも同じ操作で切り離せます（ペインを窓に切り離す）。

タブの境界線は、手で動かしたものだけが位置を覚えます。

ダブルクリックで、その並びを均等に戻せます。

成果物を読む#

Markdown のプレビューが、記号のままではなく本来の形で出ます。表、太字、番号付きリスト、引用、チェックリスト、脚注、画像まで描きます。

紙の色は選んでいるテーマに合わせて変わり、狭いペインでは表がカードに組み替わります。

プレビューの中のリンクも押せるようになりました。

PDF は、ターミナルに出たパスから、ほかの文書と同じようにペインで開きます（読むだけです）。

文書を開いたペインには、形式ごとの印が付きます（成果物をプレビューする）。

txt、log、text をアプリ内で読めます。文字コードを自動で判定し、UTF-8 以外の場合はその旨を表示します。テキストとログは読むだけで、保存はできません（テキストやログを読む）。

HTML は専用の表示画面で描くので、重い文書を開いたときもターミナルが固まりにくくなりました。文書の JavaScript と相対パスの画像も表示できます。

外部リンクは既定ブラウザで開き、ログイン画面はプレビュー内では開けません。編集に入るときだけ、従来の表示枠へ自動で切り替わります。

変わっていないファイルを開き直しても、読み直さずに読んでいた位置を保ちます。

Word と PowerPoint の画像も表示します。Web 上のリンク画像は自動で取りに行かず、出せない画像には理由を残します。

Excel の画像は表の後ろに並びますが、グラフは表示しません（Office 文書の画像）。

ペインをまとめ直す#

再配置は、有効な案があれば 1 回の AI 分析で表示します。名前が重なったワークスペースには連番を付け、変更を警告で知らせます。

分析が失敗しても、表示済みの案と編集は残ります。理由は案ごとに確認でき、後から完成した AI の案にも再生成せず切り替えられます（再配置案の見方）。

「設定 → AI」に、Jev を使う再配置の設定が加わりました。接続テストで確かめてから有効にし、案件別、役割別、現在の位置を生かす 3 案を作れます。

既定は無効です（Jev の設定）。

情報不足や確信度の低い分類は保留し、空のシェルは現在の位置に残します。

適用後に移動先を表示し、アプリ下部の「元に戻す」から戻せます。

API の混雑やタイムアウトでは、失敗した通信だけを最大 1 回やり直します。認証、残高、応答形式のエラーでは再試行しません。

スマホからつなぐ#

設定の入口は「スマホから使う」になりました。内蔵のモバイル画面はなくなり、「ポケットmycmux」へつなぐ形です。QR コードは Tailscale で配信しているときだけ出て、読み取るとブラウザで開きます（接続の条件）。

macOS での使い勝手#

ショートカットが Cmd で効くようになりました。Ctrl はタブの中のシェルへそのまま渡ります。

閉じるボタンと Cmd+W は窓を隠すだけになり、終了は Cmd+Q になりました。作業は終了のときに保存します。

切り離した窓は標準の枠を持つので、窓を整えるアプリからも掴めます（macOS での違い）。

テキストプレビューでは、HTML の閉じタグをファイルへのリンクと取り違えなくなりました。

エージェントの起動と委譲#

起動パネルの claude-codex は 1 行にまとまり、モデルは claude-codex の設定から読むようになりました。設定で足したモデルは、そのままチップに出ます（エージェントを起動する）。

委譲の CLI から、ランチャーで選ぶのと同じモデルと effort を渡せます。指示書、引き継ぎ、再開と一緒に指定しても渡ります。

シェル、Web、Codex と Grok の再開では、指定を起動前に断ります。

CLI の version で、稼働中の mycmux の版と使える機能を読めます。

send --enter は Enter を 1 回だけ押します。受理を確かめられないときは「不明」を返し、押し直しません。

裏で作ったワークスペースを片づける workspace-close も加わりました（ほかのサブコマンド）。

エージェント連携#

「設定 → AI」の「エージェント連携」で、Claude Code、Codex、Grok の hook の状態を見られます。「入れる」「直す」「外す」を選べます。

CLI の hooks-status でも導入状態を読めます。設定は変えません。

アカウントの自動切り替え#

「設定 → アカウント・使用量」で、切り替え先の「候補」をエージェントごとに選べます。

新しく登録したアカウントは最初から候補に入ります。

候補に空きがなければ知らせて、オンのまま待ちます。

知らせと見た目#

最後の出力から 60 秒を過ぎたセッションを、プロセスが残っていても待機とみなす判定が加わりました。入力待ちや完了が明示されていれば、その状態を保ちます。この判定は、socket で状態を読む側（ポケットの状況画面や委譲 CLI）で使います。ダッシュボードの表示は、この判定を使っていません。

右下に知らせるのは、人の操作が要る 3 種類だけになりました。判断を待っている、作業が検収で不合格になった、送信されていない入力が残っている、の 3 つです（見守りと無応答の検知）。

同梱の壁紙は、再配布の権利を確かめられた 11 枚に絞りました。

キャラは、新しく入れたときは表示しない状態から始まります（見た目やキーを変える）。
