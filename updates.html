最近の変更

しばらく使っていなかった方に向けて、操作に関わる変更をまとめています。更新は「設定 → アプリ情報 → 更新を確認」から行えます。

更新、要望、タブごとのログイン#

新しい版があると画面右上に青い更新マークが現れます。「設定 → アプリ情報 → 更新を確認」からも同じ確認枠を開き、「更新して再起動」か「あとで」を選べます。右上のメールアイコンから、送り先を設定したうえでスクショや内容を添えて改善の要望を送れます。

ランチャーや新規ワークスペースではタブごとにアカウントを選び、未登録なら「タブでも使う」から登録できます。

エージェントのタブは会話の表示と端末の表示を切り替えられます。タブや窓を表示場所の中央に落とすと合流し、文脈の引き継ぎにはしおりを使います。ダッシュボードは切り離した窓でも使え、ふりかえりには日ごとの積み上げ棒と分析の見出しが並びます。

アカウントの登録と会話の表示を確認できます。

使う AI だけを選び、起動する#

「設定 → 作業 → 使うサービス」で、起動や再開の画面に出すサービスを選べます。初回の確認後は Claude Code と Codex に加え、この PC で見つかった CLI を表示します。オフにしたサービスの記録済みのセッションや使用量も残ります。

Cursor は cursor-agent を別に入れ、起動メニューからモデルを選んで使います。会話の復元には対応せず、再起動すると起動メニューに戻ります。claude-codex で新しく起動したタブは、青い Claude Codex の印で見分けられます。

使うサービスの選び方と起動の手順を確認できます。

普通のターミナルと、1 回だけのコマンド実行#

起動メニューの「ターミナル」から、普通のシェルを開けます。そこで claude や codex と打っても、mycmux の連携付きで起動します。検索欄の 1 行を「ターミナルで実行」で新しい端末へ流すこともできます。

起動用の入力は保存せず、アプリを再起動したときにも流し直しません。ターミナルから始める手順に、入力の制限をまとめています。

タブの見出しから、並べる、戻す#

会話や資料の画面 1 つを「タブ」と呼び、画面を割った場所を「表示場所」と呼びます。見出しは 1 段で、「裏 N」から同じ場所のタブを選べます。追加や名前の変更などの操作は「⋮」にあります。

「右にタブを開く」は見出しにも表示し、設定で下へ開くボタンも出せます。狭いときは「⋮」から開きます。

名前のすぐ右の「×」は表示中のタブだけ、右端の「×」は裏のタブもまとめて閉じます。右端の「×」は裏のタブがあるときだけ出て、狭いときは「⋮」から操作します。

見出しを引き出すと別の窓になり、戻すときは入る場所の印を確かめます。再起動後も窓のまとまり、位置、大きさが戻ります。

倍率が違う画面へ運んだとき、つかんだ位置と窓がずれる問題も修正しています。

「タブ再配置」の「属性でまとめる」は、近い属性の小さな案件を 2〜3 件でまとめます。AI がオフでも、登録情報で案件を確定できるタブから案を作ります。「稼働中だけ」「メインだけ」も引き続き使えます。

掃除では名前、判定、理由を確認してから閉じます。

裏のタブの一覧や「⋮」は、分割境界や Web の本文に隠れないようになりました。開いたまま画面の大きさや分割位置を変えても、画面内に収めます。別のワークスペースへ移ると、元のメニューは閉じます。

「タブのフォーカス」で、端末やランチャーにマウスを乗せて入力先を切り替えられます。既定はクリックです。編集中、変換中、メニューやダイアログの表示中には切り替えません。ドラッグ中、文字の選択中、非アクティブな窓でも切り替えを抑えます。

タブと窓の使い方に、操作と注意点があります。

作業名の根拠と、読めない理由を確かめる#

Claude Code の会話の題名を優先し、題名がなければ指示から分かる作業名を使います。それもなければ起動時の名前を使い、手で付けた名前は変えません。そのタブのものだと確認できる材料だけで名前を付けます。

分からない場合は「作業内容未取得」と理由を表示します。材料が一時的に読めない場合は、最後の名前を「前回」の印つきで約 30 分残します。中断や別の依頼への変更後は、前の作業名を使いません。名前の付け方に、優先順とワークスペース名の扱いをまとめています。

会話の全過去を読み、続きを開く#

Claude Code と Codex の会話履歴は、全過去をページごとに読めます。端末の表示で上へホイールを回すか、「⋮」の「会話履歴を開く」から開きます。検索は新しい発言から探し、日本語の変換中には検索や移動をしません。

再起動時の Codex は、保存された会話 ID で同じ会話に戻ります。復元できない場合は、そのタブで新しい会話を始め、一度だけ知らせます。Claude の再開では、最後の返答に記録された effort（考える深さ）を読み取ります。

別のタブで動いている会話は、そこへ移るか、確認して開き直すかを選べます。履歴の読み方と再開の選択肢にまとめました。

返事待ちと報告を見渡す#

サイドバーの「ライブの画面」で、作業中のタブの末尾と動きの事実を見られます。マウスやキーで選ぶと最大 3 行を開き、押すとそのタブへ移ります。

吹き出しには状態と、その状態になってからの時間が出ます。回答待ちと承認待ちは黄色、止まっている状態や進んでいない状態は赤です。画面の読取時刻は出しません。

ダッシュボードでは、長い道具や見張りの待機を「作業中」として扱います。委譲元が動いている間の完了は、「その他」に「委譲元の確認待ち」と表示します。

上の帯の受け取り箱ボタンは表示しません。外部の報告が届いた通知の「開く」から、最近 20 件を確認できます。

状態と報告の見方に、区分と確認のしかたがあります。

設定、指示、ログをひとつの入口から読む#

エージェント設計は、「しくみ」の地図から始まります。「読み方」で、設定や指示がいつ読まれるかを確かめられます。本文、履歴の比較、HTML 設計書への書き出しにも進めます。

スキルの棚と、使用量のグラフは、この画面の「スキル」「ふりかえり」から開きます。AI ログは「ふりかえり」を選ぶまで読み込みません。点検では、無効や手動専用のスキル、現在のアカウント、推定と不明を区別します。

端末フォントの設定画面には 10 プリセットが並び、HackGen Console も同梱しました。アプリのボタンや入力欄にも効き、ライセンスは「アプリ情報」から読めます。エージェント設計と書体の設定に詳しくあります。

成果物の隣で、指摘を作る#

端末のパスから、Markdown、HTML、Office、PDF、テキストを開けます。Windows のローカル HTML では、文字の範囲や図、写真を選んで指摘を作れます。原文、前後の文、見出しと画像の保存先を添えた依頼文をコピーします。

画面が変わったときは、古い画像のままコピーせず、箇所を選び直します。成果物の確認と指摘に、対応する形式と手順があります。

アカウント、接続と表示を確かめる#

アカウント一覧で、契約プラン、取得できた契約の日付、リセット券を確かめられます。券は残数と期限を読み、確認してから 1 枚使います。Mac の Claude アカウント追加は、Keychain に保存されたログインも読み取ります。

外部の Web タブの権限を本体と分けました。データの一部を読める経路は残るため、信頼できないサイトは開かないでください。導入済みの制御 CLI は更新時に追従し、手で変更したものは控えを残して保護します。

画面の崩れを調べる記録は設定から有効にでき、通常はオフです。キャラは使用中のものを避ける抽選が既定で、壁紙は 11 枚です。アカウントと設定とポケットの入手状況を確認できます。

開発者向けの API と試験機能は、いま動いているものにまとめています。
